ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ ДЛЯ ВЫПОЛНЕНИЯ РАБОТЫ 

Полиморфизм – это способность объектов с разной реализацией иметь  общий интерфейс. В Java полиморфизм позволяет одному и тому же коду  работать с объектами разных классов. 

Виды полиморфизма в Java: 

• Статический – Перегрузка (Overloading) – Решается на этапе  компиляции – Одинаковые имена, разные параметры  

• Динамический – Переопределение (Overriding) – Решается во время  выполнения – Одинаковые имена и параметры  

Перегрузка – это механизм, позволяющий в одном классе объявить  несколько методов с одинаковым именем, но разными параметрами  (количество, тип или порядок).

Правила перегрузки 

− Имя метода должно совпадать  

− Параметры должны различаться (Количество, тип, порядок) − Тип возврата может различаться (“int”, “double”, “String”) − Модификаторы могут различаться ( “public”, “static”, “private” ) − Исключения могут различаться ( “throws Exception” ) Что НЕ является перегрузкой

Правила переопределения 

− Имя метода должно совпадать с родительским  

− Параметры должны совпадать с родительскими  

− Тип возврата должен совпадать или быть ковариантным (подтипом)  − Модификатор доступа не может быть более строгим (public \> protected  \> default \> private)  

− Исключения не может выбрасывать более широкие исключения  − Аннотация рекомендуется использовать “@Override”
