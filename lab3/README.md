## Теория для защиты

### Контрольные вопросы (из задания)

1. **Что такое строка?**
   Упорядоченная последовательность символов. В Java строка — это объект класса `String`, неизменяемый (immutable).

2. **Как создаётся строка?**
   - Литерал: `String s = "Hello";`
   - Через new: `String s = new String("Hello");`
   - Из массива символов: `new String(charArray);`

3. **Как выглядит массив строк?**
   `String[] arr = {"Java", "Python", "C++"};` — массив ссылок на объекты String.

4. **Что такое конкатенация?**
   Слияние строк. Оператор `+` или метод `concat()`.

5. **Как происходит слияние строк?**
   `"Hello" + " " + "World"` = `"Hello World"`. Оператор `+` — единственный перегруженный оператор в Java.

6. **Какие классы работают с регулярными выражениями?**
   `Pattern` (компиляция шаблона) и `Matcher` (поиск совпадений).

### Дополнительные вопросы

**Класс String:**
- `String` неизменяем — любой метод создаёт **новый** объект
- Литералы хранятся в String Pool (переиспользуются)
- `concat()` быстрее `+` при большом количестве конкатенаций

**StringBuilder vs StringBuffer:**
- `StringBuilder` — не потокобезопасный, быстрее (однопоточные приложения)
- `StringBuffer` — синхронизированный (многопоточные приложения)

**Форматирование:**
- `printf()` — форматированный вывод (`%s`, `%d`, `%f`, `%n`)
- `%-15s` — строка влево, `%10.2f` — число вправо с 2 знаками

**Регулярные выражения:**
- `\d` — цифра `[0-9]`, `\w` — буква/цифра/ _, `\s` — пробел
- `*` — 0+, `+` — 1+, `?` — 0 или 1, `{n}` — ровно n
- `Pattern.compile()` → `matcher.find()` → `matcher.group()`
