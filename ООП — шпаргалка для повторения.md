# 1. Класс и объект

```java
[модификатор] class Имя {
    поля;          // состояние
    конструкторы;  // создание
    методы;        // поведение
}
```

```java
public class Student {
    private String name;               // поле (атрибут) — состояние объекта
    private int age;

    public Student(String name, int age) {   // конструктор
        this.name = name;                    // this снимает конфликт имён
        this.age = age;
    }

    public String getName() { return name; } // метод (геттер)
    public void displayInfo() { System.out.println(name + ", " + age); }
}

Student s = new Student("Иван", 20);   // экземпляр класса
s.displayInfo();
```

## Поля

- **Поля** описывают состояние объекта, у каждого объекта **своя копия**.
- **Локальные переменные** (в методах) — только внутри метода, по умолчанию **не** инициализируются.
- Поля класса инициализируются значениями по умолчанию: `0`, `0.0`, `false`, `null` и т.д.

## Методы

- Сигнатура: `[модификатор] ТипВозврата имя(параметры) { ... }`
- `void` — ничего не возвращает; `return` — возврат значения и выход из метода.
- **Перегрузка (overload):** методы с одним именем, но разными параметрами (в одном классе).

```java
public void applyDiscount() { ... }          // скидка по умолчанию
public void applyDiscount(double percent) { ... }  // заданный процент
```

## Конструкторы

- Имя = имя класса, **нет типа возврата**.
- Вызывается автоматически при `new`.
- Если не объявлен ни один — компилятор создаст **конструктор по умолчанию** без параметров.
- Как только объявлен свой конструктор — конструктор по умолчанию **не** создаётся.
- Конструкторы можно перегружать.

## new, ссылки, null

```java
Cat a = new Cat();   // объект в куче, a — ССЫЛКА на него
Cat b = a;           // копируется ссылка: a и b — один и тот же объект!
b.name = "Барсик";   // изменится и для a
```

- `null` — ссылка ни на что; вызов метода/поля у `null` → `NullPointerException`.
- `==` для объектов сравнивает **ссылки**, содержимое — только `equals()`.

## Массив объектов

```java
Book[] books = { new Book("Война и мир", 1869), new Book("Онегин", 1833) };
for (Book b : books) System.out.println(b);   // нужен toString()
```

# 2. Инкапсуляция

Принцип: данные + методы их обработки в одном классе, доступ к состоянию ограничен (поля `private`).

**Зачем:** спрятать реализацию, защитить данные от некорректного изменения, дать контролируемый доступ.

## Модификаторы доступа

| Модификатор | Класс | Пакет | Наследники | Все |
|-------------|:-----:|:-----:|:----------:|:---:|
| `public` | + | + | + | + |
| `protected` | + | + | + | – |
| `default` (без слова) | + | + | – | – |
| `private` | + | – | – | – |

## Геттеры и сеттеры

```java
class Ticket {
    private double price;

    public double getPrice() { return price; }             // геттер — чтение
    public void setPrice(double price) {                   // сеттер — запись с проверкой
        if (price >= 0) this.price = price;                // некорректное значение игнорируется
    }
}
```

Итог: поле скрыто, состояние нельзя сломать извне — только через проверяемые методы.

# 3. Наследование

```java
class Animal {                       // суперкласс (родитель)
    protected String name;
    public void eat() { System.out.println(name + " ест"); }
}

class Cat extends Animal {           // подкласс (потомок) — наследует поля и методы
    private String color;

    public Cat(String name, String color) {
        super(name);                 // вызов конструктора родителя — ПЕРВОЙ строкой
        this.color = color;
    }

    @Override
    public void eat() {              // переопределение метода родителя
        super.eat();                 // можно вызвать логику родителя
        System.out.println("И ещё молоко");
    }
}
```

## Что наследуется

- `public` и `protected` члены — наследуются и доступны напрямую.
- `private` члены — наследуются физически, но напрямую **недоступны** (только через public/protected методы родителя).
- `default` члены — доступны потомку только в том же пакете.
- **Конструкторы не наследуются** → вызываются через `super(...)`.

## super и this

| | `this` | `super` |
|--|--------|---------|
| Что это | ссылка на текущий объект | обращение к части класса-родителя |
| Вызов конструктора | `this(...)` — свой другой конструктор | `super(...)` — конструктор родителя |
| Метод | `this.m()` — свой | `super.m()` — родителя (для переопределённых) |

- `super(...)` / `this(...)` — всегда **первая** строка конструктора.
- Если явно не написан — компилятор вставит `super()` без аргументов. Если у родителя такого конструктора нет — ошибка компиляции.

## Переопределение (override)

- Одинаковые имя и параметры, тот же/совместимый (ковариантный) тип возврата.
- Нельзя сузить модификатор доступа (было `public` — должно остаться `public`).
- Нельзя переопределить `final`-метод.
- `@Override` — аннотация-проверка (опечатался — компилятор подскажет).
- **Overload vs override:**

| | overload (перегрузка) | override (переопределение) |
|--|----------------------|----------------------------|
| Где | в одном классе | в потомке |
| Параметры | разные | одинаковые |
| Выбор | на этапе компиляции | динамически во время выполнения |

## Полиморфизм

```java
Animal a = new Cat("Барсик", "рыжий");  // upcast: ссылка родителя → объект потомка
a.eat();                                // вызовется ПЕРЕОПРЕДЕЛЁННАЯ версия Cat

if (a instanceof Cat) {                 // проверка типа
    Cat c = (Cat) a;                    // downcast — явное приведение вниз
    c.прыгнуть();
}
```

- **Динамическое связывание:** какой метод выполнится, решается по **фактическому** типу объекта, а не по типу ссылки.
- Через ссылку родителя видны только члены родителя (метод потомка — только если переопределён).
- Неверный downcast → `ClassCastException`; поэтому проверяют `instanceof`.

## Класс Object (корень иерархии)

Все классы неявно наследуют `Object`. Полезно переопределять:

```java
@Override public String toString() { return name + ", " + age; }   // печать объекта
@Override public boolean equals(Object o) { ... }                  // сравнение по содержимому
@Override public int hashCode() { ... }                            // вместе с equals
```

## final и abstract (кратко)

- `final` **поле** — константа; `final` **метод** — нельзя переопределить; `final` **класс** — нельзя наследовать.
- `abstract` **метод** — без тела, потомок **обязан** реализовать; класс с abstract-методом сам объявляется `abstract` (объект не создать).

# 4. static

Принадлежит **классу**, а не объекту; существует в одном экземпляре на всех.

```java
class Person {
    int age;                          // у каждого объекта своя копия
    static int retirementAge = 65;    // одно значение на весь класс

    static { retirementAge = 65; }    // статический инициализатор — ОДИН раз при загрузке класса

    void checkAge() {
        if (age >= retirementAge) ... // обычный метод ВИДИТ статическое поле
    }

    static double avg() { ... }       // статический метод
}

Person.retirementAge;                 // доступ через ИМЯ КЛАССА
Person.avg();                         // объект для вызова не нужен
```

## Правила

- Статический метод **не может** напрямую обращаться к нестатическим полям и методам (у него нет `this` — объекта может не существовать).
- Обратное можно: обычный метод свободно использует статические члены.
- `static final` — константа класса: `public static final double PI = 3.14;`
- Память под статические поля выделяется при загрузке класса — **до** создания объектов.

## Порядок выполнения

1. При **первом** обращении к классу — статические поля и статические инициализаторы (один раз).
2. При каждом `new`: поля объекта → инициализаторы → конструктор.

```
Static initializer      ← один раз
Constructor             ← при каждом new
```

## static vs не-static

| Признак | обычное поле/метод | `static` |
|---------|--------------------|----------|
| Владелец | объект | класс |
| Экземпляров | по одному на объект | один на класс |
| Вызов | `obj.f()` | `Class.f()` |
| `this` | есть | нет |
| Живёт | пока жив объект | всё время работы класса |

**Почему `main` — static:** JVM вызывает `main` сама, до/без создания объекта главного класса.

## Шаблон: статистика на счётчиках

```java
public class Student {
    private static int totalStudents;   // счётчик объектов
    private static int totalCourses;    // сумма курсов

    public Student(int course) {
        totalStudents++;
        totalCourses += course;
    }

    public static double getAverageCourse() {
        if (totalStudents == 0) return 0.0;          // защита от деления на ноль
        return (double) totalCourses / totalStudents;
    }
}
```

# 5. enum (повторить перед ОКР)

```java
public enum Gender {
    MALE("мужской"), FEMALE("женский");   // элементы создаются БЕЗ new

    private final String ru;
    Gender(String ru) { this.ru = ru; }    // конструктор не может быть public/protected

    @Override public String toString() { return ru; }
}
```

- Типобезопасный набор констант (альтернатива `static final int`).
- Это класс, наследник `java.lang.Enum`; может иметь поля, конструкторы, методы.
- Методы: `values()`, `valueOf("MALE")`, `ordinal()` (позиция с 0), `name()`, `compareTo()`.
- Запрещено: наследовать/наследоваться, быть abstract, создавать через `new`.

# 6. Ловушки и частые вопросы

1. **`==` vs `equals()`** — ссылки vs содержимое. Для своих классов equals переопределяют.
2. **overload vs override** — разные параметры в одном классе vs одинаковые в потомке.
3. **Что наследуется, а что нет** — конструкторы НЕТ; private наследуется, но недоступен.
4. **`super()` без аргументов** — вставляется компилятором, если явно не указан другой вызов; родитель без пустого конструктора → ошибка.
5. **static → non-static** — нельзя, **non-static → static** — можно.
6. **Изменение объекта через ссылку** — `Cat b = a;` не копирует объект.
7. **Полиморфизм** — метод выбирается по фактическому типу объекта; поля — по типу ссылки (поля не полиморфны!).
8. **final** — поле/метод/класс: константа / нельзя переопределить / нельзя наследовать.
9. **Порядок инициализации** — статика один раз → при new: поля → конструктор.
10. **enum с конструктором** — конструктор выполняется для каждого элемента автоматически при загрузке перечисления.

# 7. Карточка-минимум (перечитать за 2 минуты)

```java
class A {                          // класс, поля private = инкапсуляция
    private int x;                 // состояние объекта
    static int count;              // состояние класса (одна копия)

    A(int x) { this.x = x; count++; }             // конструктор, this
    public int getX() { return x; }               // геттер
    public void setX(int x) { if (x>0) this.x = x; }
    @Override public String toString() { return "A:"+x; }
    static int getCount() { return count; }       // вызов A.getCount()
}

class B extends A {                // наследование
    B(int x) { super(x); }         // конструктор родителя
    @Override public String toString() { return "B:" + getX(); }  // переопределение
}

A obj = new B(5);                  // полиморфизм (upcast)
obj.toString();                    // "B:5" — по фактическому типу
```
