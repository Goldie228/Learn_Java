# Конспект: Лабораторная работа №8

## 1. Наследование и super

Наследование — механизм, при котором наследник получает поля и методы
суперкласса. Объявляется через `extends`; суперкласс только один.
Наследование выражает отношение «является»: `GamingPC` является `Computer`.

```java
class Computer {
    private String processor;
    public Computer(String p) { this.processor = p; }
}
class GamingPC extends Computer {
    private String videoCard;
    public GamingPC(String p, String v) {
        super(p);              // конструктор суперкласса
        this.videoCard = v;
    }
}
```

`super(...)` вызывается первой строкой конструктора; `super.method()` —
обращение к реализации метода суперкласса. Приватные поля родителя
наследнику недоступны напрямую — только через его методы.

## 2. Переопределение методов

Переопределение (`@Override`) — своя реализация унаследованного метода с
той же сигнатурой. Аннотация помогает компилятору заметить опечатку.

```java
@Override
public String getPerformance() {
    return "Высокая производительность";
}
```

Перегрузка — это методы с одним именем и разными параметрами; она не
связана с наследованием и не даёт полиморфизма.

## 3. Полиморфизм и instanceof

Ссылке базового типа можно присвоить объект наследника (upcasting), а JVM
выбирает метод по фактическому классу объекта (динамическое связывание).

```java
Computer[] computers = {
    new GamingPC("Intel Core i9", 32, 2000, "RTX 4080"),
    new OfficePC("Intel Core i5", 8, 256, 21.5)
};
for (Computer c : computers) {
    System.out.println(c.getPerformance());
}
```

Уникальные методы наследника через ссылку базового типа недоступны — нужны
проверка типа и приведение вниз. Без проверки — `ClassCastException`.

```java
if (c instanceof GamingPC gaming) {  // сопоставление с образцом
    gaming.playGame();
}
```

## 4. Конструкторы super и this

```java
public Point2D(int x, int y) { super(x); this.y = y; }
public Point3D(int x, int y, int z) { super(x, y); this.z = z; }
public Point3D() { this(-1, -1, -1); }  // вызов своего конструктора
```

Сначала выполняется конструктор суперкласса (сверху вниз по цепочке),
затем поля и тело конструктора наследника. `this(...)` вызывает другой
конструктор того же класса и тоже стоит первой строкой.
