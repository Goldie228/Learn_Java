## Теория для защиты

### Контрольные вопросы (из задания)

1. **Какие способы создания массивов существуют:**
   - Через `new`: `int[] arr = new int[5];`
   - Списком инициализации: `int[] arr = {1, 2, 3};`
   - Через `new` со списком: `int[] arr = new int[] {1, 2, 3};`
   - Двумерный: `int[][] m = new int[3][4];` или `int[][] m = {{1,2},{3,4}};`

2. **Как можно заполнять массив:**
   - Вручную: `arr[0] = 10;`
   - Через цикл и `Scanner`: `for (int i=0; i<arr.length; i++) arr[i] = sc.nextInt();`
   - Случайными числами: `arr[i] = rand.nextInt(100);`
   - `Arrays.fill(arr, value);` — заполнение одним значением

3. **Типы литералов Java** (из прошлой лабы):
   - Целые: `42`, `100L` (long)
   - Вещественные: `3.14`, `2.5f` (float), `2.5` (double)
   - Логические: `true`, `false`
   - Символьные: `'A'`
   - Строковые: `"Hello"`

### Дополнительные вопросы, которые могут спросить

**Основы массивов:**
- С какого индекса начинается нумерация? (с 0)
- Что такое `length` — это метод или поле? (поле, без скобок)
- Что произойдёт при обращении к `arr[10]` при размере 5? (`ArrayIndexOutOfBoundsException`)

**Копирование массивов:**
- Можно ли присвоить `arr2 = arr1`? (да, но это копирование **ссылки**, а не данных — оба указывают на один объект)
- Как правильно скопировать массив? (через цикл или `Arrays.copyOf()`)

**Двумерные массивы:**
- Что такое «jagged array»? (массив строк разной длины)
- Как узнать количество столбцов в строке `i`? (`matrix[i].length`)
- В чём разница `matrix.length` и `matrix[0].length`? (первое — число строк, второе — число столбцов первой строки)

**Диагонали матрицы:**
- Как найти элемент главной диагонали? (`matrix[i][i]`)
- Как найти элемент побочной диагонали? (`matrix[i][n - 1 - i]`)
- Что такое магический квадрат? (суммы строк, столбцов и диагоналей равны)

### Что рассказать о своей работе

При демонстрации программы рассказать:

4. Используется поле `length` для определения размера
5. Показать работу с тестовыми данными
