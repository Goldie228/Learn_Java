# Файловый ввод-вывод (ЛР14)

> [!abstract] Одной фразой
> Байтовые потоки работают с сырыми байтами, символьные — с текстом.
> В современном Java текст читают и пишут через `Files` + UTF-8.

## Две иерархии

| Назначение | Байты | Символы |
|------------|-------|---------|
| Ввод | `InputStream` | `Reader` |
| Вывод | `OutputStream` | `Writer` |
| Файл | `FileInputStream` / `FileOutputStream` | `FileReader` / `FileWriter` |
| Буфер | `BufferedInputStream` / `BufferedOutputStream` | `BufferedReader` / `BufferedWriter` |

- Байтовые — для картинок, архивов, бинарных данных.
- Символьные — для текста (Unicode).
- `BufferedReader`/`BufferedWriter` добавляют буфер и построчные методы.

## `File` vs `Path` / `Files`

`File` — старый класс: информация о файле и каталоге, но не содержимое.

```java
File file = new File("data/info.txt");
System.out.println(file.getName());
System.out.println(file.length());
System.out.println(file.getAbsolutePath());
System.out.println(file.exists());
System.out.println(file.isDirectory());
System.out.println(file.isFile());
```

`Path` + `Files` (Java 7+) — современный способ:

```java
Path path = Path.of("data/info.txt");
Files.exists(path);
Files.isDirectory(path);
Files.isRegularFile(path);
Files.size(path);
Files.getLastModifiedTime(path);
Files.createDirectories(path.getParent());
Files.deleteIfExists(path);
```

> [!tip] На защите
> «`File` — это путь и метаданные, `Files` — операции с содержимым.
> В новом коде я использую `Path`/`Files`, потому что они лучше работают
> с кодировками, символическими ссылками и ошибками».

## Чтение текста

```java
Path path = Path.of("data/info.txt");

// весь файл сразу
List<String> lines = Files.readAllLines(path, StandardCharsets.UTF_8);
for (String line : lines) System.out.println(line);

// построчно, с автозакрытием
try (BufferedReader reader = Files.newBufferedReader(path, StandardCharsets.UTF_8)) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}
```

## Запись текста

```java
Path path = Path.of("data/out.txt");
Files.createDirectories(path.getParent());

try (BufferedWriter writer = Files.newBufferedWriter(path, StandardCharsets.UTF_8)) {
    writer.write("Первая строка");
    writer.newLine();
    writer.write("Вторая строка");
    writer.newLine();
}
```

Дозапись:

```java
Files.write(path, List.of("ещё строка"), StandardCharsets.UTF_8,
        StandardOpenOption.CREATE, StandardOpenOption.APPEND);
```

## Числа в текстовом файле

Одно число на строку — самый простой формат.

```java
static void writeInts(Path file, List<Integer> values) throws IOException {
    Files.createDirectories(file.getParent());
    try (BufferedWriter writer = Files.newBufferedWriter(file, StandardCharsets.UTF_8)) {
        for (int value : values) {
            writer.write(String.valueOf(value));
            writer.newLine();
        }
    }
}

static List<Integer> readInts(Path file) throws IOException {
    List<Integer> values = new ArrayList<>();
    for (String line : Files.readAllLines(file, StandardCharsets.UTF_8)) {
        if (!line.isBlank()) {
            values.add(Integer.parseInt(line.trim()));
        }
    }
    return values;
}
```

```java
static List<Double> readDoubles(Path file) throws IOException {
    List<Double> values = new ArrayList<>();
    for (String line : Files.readAllLines(file, StandardCharsets.UTF_8)) {
        if (!line.isBlank()) values.add(Double.parseDouble(line.trim()));
    }
    return values;
}

static void writeDoubles(Path file, List<Double> values) throws IOException {
    Files.createDirectories(file.getParent());
    try (BufferedWriter writer = Files.newBufferedWriter(file, StandardCharsets.UTF_8)) {
        for (double value : values) {
            writer.write(String.valueOf(value));
            writer.newLine();
        }
    }
}
```

## Информация о файле

```java
static void printFileInfo(Path path) throws IOException {
    System.out.println("Имя: " + path.getFileName());
    System.out.println("Размер: " + Files.size(path) + " байт");
    System.out.println("Изменён: " + Files.getLastModifiedTime(path));
    System.out.println("Родитель: " + path.getParent());
    System.out.println("Путь: " + path);
    System.out.println("Абсолютный путь: " + path.toAbsolutePath());
    System.out.println("Существует: " + (Files.exists(path) ? "да" : "нет"));
    System.out.println("Чтение: " + (Files.isReadable(path) ? "да" : "нет"));
    System.out.println("Запись: " + (Files.isWritable(path) ? "да" : "нет"));
    System.out.println("Каталог: " + (Files.isDirectory(path) ? "да" : "нет"));
    System.out.println("Файл: " + (Files.isRegularFile(path) ? "да" : "нет"));
}
```

### 2. 10 чисел: разность max и min

```java
static int differenceMaxMin(List<Integer> values) {
    if (values.isEmpty()) throw new IllegalArgumentException("Список пуст");
    int min = values.get(0);
    int max = values.get(0);
    for (int v : values) {
        if (v < min) min = v;
        if (v > max) max = v;
    }
    return max - min;
}
```

```java
List<Integer> numbers = new ArrayList<>();
Scanner sc = new Scanner(System.in);
while (numbers.size() < 10) {
    System.out.print("Число " + (numbers.size() + 1) + ": ");

        numbers.add(Integer.parseInt(token));
    } catch (NumberFormatException e) {
        System.out.println("Это не целое число, повторите");

}
```

### 3. Random, кратные 7

```java
static void createRandomIntFile(Path file, int count, int min, int max) throws IOException {
    Files.createDirectories(file.getParent());
    Random random = new Random();
    int bound = max - min + 1;
    try (BufferedWriter writer = Files.newBufferedWriter(file, StandardCharsets.UTF_8)) {
        for (int i = 0; i < count; i++) {
            writer.write(String.valueOf(random.nextInt(bound) + min));
            writer.newLine();
        }
    }
}

static void splitMultiples(Path source, Path multiples, Path rest, int divisor)
        throws IOException {
    List<Integer> g = new ArrayList<>();
    List<Integer> h = new ArrayList<>();
    for (int value : readInts(source)) {
        if (value % divisor == 0) g.add(value);
        else h.add(value);
    }
    writeInts(multiples, g);
    writeInts(rest, h);
}
```

```java
Path f = Path.of("data/task3/f.txt");
Path g = Path.of("data/task3/g.txt");
Path h = Path.of("data/task3/h.txt");
createRandomIntFile(f, 20, -100, 100);
splitMultiples(f, g, h, 7);
System.out.println("f: " + readInts(f));
System.out.println("g (кратные 7): " + readInts(g));
System.out.println("h (остальные): " + readInts(h));
```

> [!note] Ноль и отрицательные
> `0 % 7 == 0`, `-7 % 7 == 0` — оба попадут в файл кратных. Это правильно.

### 4. 15 значений силы тока, среднее

```java
static double average(List<Double> values) {
    if (values.isEmpty()) return 0.0;
    double sum = 0;
    for (double v : values) sum += v;
    return sum / values.size();
}
```

## Частые ошибки

| Ошибка | Последствие | Как правильно |
|--------|-------------|---------------|
| Забыли `close()` | файл занят, данные не сброшены | try-with-resources |
| Не указали UTF-8 | кракозябры | `StandardCharsets.UTF_8` |
| Не создали каталог | `NoSuchFileException` | `Files.createDirectories` |
| `parseInt` без `try` | падение на буквах | `NumberFormatException` |
| Читают байты как текст | неверные символы | `Reader`/`Files.newBufferedReader` |
| `FileOutputStream` без append | файл перезаписан | `StandardOpenOption.APPEND` |

## Что спросят на защите

1. **Что такое поток?** Абстракция источника/приёмника данных.
2. **Родители байтовых/символьных?** `InputStream`/`OutputStream`, `Reader`/`Writer`.
3. **Методы `InputStream`?** `read()`, `read(byte[])`, `skip()`, `available()`, `close()`.
4. **Методы `OutputStream`?** `write(int)`, `write(byte[])`, `flush()`, `close()`.
5. **Зачем `File`?** Путь и метаданные, не содержимое.
6. **`FileInputStream` vs `FileOutputStream`?** Чтение байтов vs запись (перезапись).
7. **Зачем буфер?** Меньше обращений к диску, быстрее.
8. **`Path`/`Files` vs `File`?** Больше возможностей, кодировки, NIO.
9. **Почему классов так много?** Разные источники, способы доступа и кодировки.
10. **Зачем try-catch?** `IOException` — checked; ресурсы надо закрывать.

> [!tip] Фраза для ответа
> «Для текста я использую `Files.newBufferedReader`/`newBufferedWriter`
> с UTF-8 и try-with-resources. Числа храню по одному на строку, при чтении
> парсю каждую строку. Ошибки ввода-вывода — checked, поэтому обрабатываю
> или пробрасываю».
