# Интерфейсы (ЛР10)

> [!abstract] Одной фразой
> Интерфейс — это контракт: «что объект умеет», без «как именно».
> Класс может реализовать сколько угодно интерфейсов.

## Синтаксис

```java
public interface Readable {
    int MAX_PAGES = 1000;          // public static final
    String read();                 // public abstract
    int getPages();

    default int readingTime() {    // готовое поведение
        return getPages() * 2;
    }

    static String format(int pages) {
        return pages + " стр.";
    }
}
```

```java
public class Novel implements Readable {
    private final int pages;
    public Novel(int pages) { this.pages = pages; }

    @Override
    public String read() { return "Читаю роман"; }

    @Override
    public int getPages() { return pages; }
}
```

## Свойства интерфейса

1. Нельзя создать объект: `new Readable()` — ошибка.
2. Нет конструкторов.
3. Поля неявно `public static final` (константы).
4. Абстрактные методы неявно `public abstract`.
5. `default`-метод (Java 8) — с телом, можно не переопределять.
6. `static`-метод (Java 8) — вызывается только через имя интерфейса.
7. `private`-метод (Java 9) — внутренний помощник `default`/`static`.
8. Интерфейс может наследовать **несколько** интерфейсов через `extends`.
9. Интерфейс не может наследовать класс и не может быть `final`.
10. Класс реализует интерфейс через `implements`.
11. Если класс не реализовал все методы — он `abstract`.
12. Реализующий метод должен быть `public`.

## Несколько интерфейсов

```java
interface Drawable { void draw(); }
interface Moveable { void move(int dx, int dy); }
interface Resizable { void resize(double factor); }

class Shape implements Drawable, Moveable, Resizable {
    private int x, y;
    private double size = 10;

    @Override public void draw() {
        System.out.println("Рисую фигуру в (" + x + ", " + y + "), размер " + size);
    }
    @Override public void move(int dx, int dy) { x += dx; y += dy; }
    @Override public void resize(double factor) { size *= factor; }
}
```

```java
Shape s = new Shape();
Drawable d = s;
Moveable m = s;
System.out.println(d instanceof Shape); // true
```

## Наследование интерфейсов

```java
interface A { void a(); }
interface B { void b(); }
interface C extends A, B { void c(); }

class Impl implements C {
    @Override public void a() {}
    @Override public void b() {}
    @Override public void c() {}
}
```

Класс обязан реализовать методы **всей** иерархии.

## `default`-методы и конфликты

```java
interface A { default String hello() { return "A"; } }
interface B { default String hello() { return "B"; } }

class C implements A, B {
    @Override
    public String hello() {
        return A.super.hello() + B.super.hello();  // явный выбор
    }
}
```

Если два интерфейса дают одинаковый `default`, класс обязан переопределить метод.

> [!warning] Ловушка
> `static`-метод интерфейса **не наследуется** классом. Вызов только:
> `Readable.format(10)`, а не `novel.format(10)`.

## Интерфейс vs абстрактный класс

| Критерий | Интерфейс | Абстрактный класс |
|----------|-----------|-------------------|
| Ключевое слово | `interface` / `implements` | `abstract class` / `extends` |
| Конструктор | нет | есть |
| Состояние объекта | нет (только константы) | любые поля |
| Реализация методов | `default`, `static`, `private` | любые конкретные |
| Множественное наследование | да (интерфейсов) | только один класс |
| Когда использовать | общий контракт, роли (`Readable`, `Lendable`) | общая база + состояние |

## Код варианта 9 (ЛР10)

```java
public interface Readable {
    String read();
    int getPages();

    default int getReadingTimeMinutes() {
        return getPages() * 2;
    }

    static String formatPages(int pages) {
        return pages + " стр.";
    }
}
```

```java
public interface Lendable {
    boolean lend();
    boolean returnBook();
    boolean isAvailable();
}
```

```java
public class Novel implements Readable, Lendable {
    private final String title;
    private final String author;
    private final int pages;
    private boolean available = true;

    public Novel(String title, String author, int pages) {
        this.title = title;
        this.author = author;
        this.pages = pages;
    }

    @Override public String read() { return "Читаю роман «" + title + "»"; }
    @Override public int getPages() { return pages; }

    @Override
    public boolean lend() {
        if (!available) return false;
        available = false;
        return true;
    }

    @Override
    public boolean returnBook() {
        if (available) return false;
        available = true;
        return true;
    }

    @Override public boolean isAvailable() { return available; }
}
```

```java
public class Textbook implements Readable, Lendable {
    private final String title;
    private final String author;
    private final int pages;
    private final String subject;
    private boolean available = true;

    public Textbook(String title, String author, int pages, String subject) {
        this.title = title;
        this.author = author;
        this.pages = pages;
        this.subject = subject;
    }

    @Override
    public String read() {
        return "Читаю учебник по предмету «" + subject + "»";
    }
    @Override public int getPages() { return pages; }

    @Override public boolean lend() {
        if (!available) return false;
        available = false;
        return true;
    }
    @Override public boolean returnBook() {
        if (available) return false;
        available = true;
        return true;
    }
    @Override public boolean isAvailable() { return available; }
}
```

### Полиморфизм через интерфейс

```java
List<Readable> books = List.of(
    new Novel("Мастер и Маргарита", "Булгаков", 480),
    new Novel("1984", "Оруэлл", 320),
    new Textbook("Информатика", "Блинов", 560, "информатика")
);

int total = 0;
for (Readable book : books) {
    System.out.println(book.read());
    System.out.println(Readable.formatPages(book.getPages()));
    System.out.println("Время: " + book.getReadingTimeMinutes() + " мин");
    total += book.getPages();
}
System.out.println("Всего страниц: " + total);
```

```java
List<Lendable> library = new ArrayList<>();
library.add((Lendable) books.get(0));   // если объект реализует Lendable
for (Lendable item : library) {
    System.out.println(item.lend());    // true
    System.out.println(item.lend());    // false — уже выдана
}
```

## Что спросят на защите

1. **Что такое интерфейс?** Контракт поведения, набор методов без состояния.
2. **Можно ли создать объект?** Нет.
3. **Какие методы бывают?** Абстрактные, `default`, `static`, `private`.
4. **Какие поля?** Только `public static final`.
5. **Чем отличается от абстрактного класса?** См. таблицу.
6. **Как реализовать?** `implements`, методы `public`.
7. **Можно ли несколько?** Да, через запятую.
8. **Может ли интерфейс наследовать интерфейс?** Да, и несколько.
9. **Что такое `default`?** Метод с реализацией, который можно не переопределять.

> [!tip] Фраза для ответа
> «Интерфейс описывает роль объекта. `Novel` и `Textbook` — разные классы,
> но оба умеют `read()` и `lend()`, поэтому с ними можно работать
> полиморфно через `Readable` и `Lendable`».
