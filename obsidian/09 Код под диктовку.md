# Код под диктовку

> [!tip] Как тренироваться
> Закрой заметку и напиши каждый шаблон в отдельном файле без подсказки.
> Потом сравни. На защите обычно просят **один** из этих каркасов плюс
> 1–2 метода по варианту.

## 1. Класс: инкапсуляция

```java
public class Student {
    private String name;
    private int course;
    private String group;

    public Student(String name, int course, String group) {
        this.name = name;
        this.course = course;
        this.group = group;
    }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getCourse() { return course; }
    public void setCourse(int course) { this.course = course; }
    public String getGroup() { return group; }
    public void setGroup(String group) { this.group = group; }

    public String displayInfo() {
        return "Студент: " + name + ", курс: " + course + ", группа: " + group;
    }
}
```

Каркас для любого задания: **3 приватных поля → конструктор → геттеры/сеттеры → `displayInfo()`**.

## 3. Абстрактный класс

```java
public abstract class Transport {
    private double capacity;
    private double speed;
    private double fuel;

    public Transport(double capacity, double speed, double fuel) {
        this.capacity = capacity;
        this.speed = speed;
        this.fuel = fuel;
    }

    public double getCapacity() { return capacity; }
    public double getSpeed() { return speed; }
    public double getFuel() { return fuel; }

    public abstract String deliver();
    public abstract double calculateTime(double distance);

    public String displayInfo() {
        return capacity + " т, " + speed + " км/ч, " + fuel + " л";
    }
}
```

```java
public class Truck extends Transport {
    private double cargoWeight;

    public Truck(double capacity, double speed, double fuel, double cargoWeight) {
        super(capacity, speed, fuel);
        this.cargoWeight = cargoWeight;
    }

    @Override public String deliver() { return "Доставляет груз по суше"; }

    @Override
    public double calculateTime(double distance) {
        if (distance < 0) throw new IllegalArgumentException("distance < 0");
        return distance / getSpeed();
    }

    @Override
    public String displayInfo() {
        return super.displayInfo() + ", груз: " + cargoWeight + " т";
    }
}
```

```java
public class Ship extends Transport {
    private double tonnage;

    public Ship(double capacity, double speed, double fuel, double tonnage) {
        super(capacity, speed, fuel);
        this.tonnage = tonnage;
    }

    @Override public String deliver() { return "Доставляет груз по воде"; }

    @Override
    public double calculateTime(double distance) {
        if (distance < 0) throw new IllegalArgumentException("distance < 0");
        return distance / (getSpeed() * 0.8);
    }

    @Override
    public String displayInfo() {
        return super.displayInfo() + ", тоннаж: " + tonnage + " т";
    }
}
```

> [!warning] Нельзя
> `new Transport(...)` — ошибка компиляции. Можно только
> `Transport t = new Truck(...)`.

```java
public class Novel implements Readable, Lendable {
    private final String title;
    private final int pages;
    private boolean available = true;

    public Novel(String title, int pages) {
        this.title = title;
        this.pages = pages;
    }

    @Override public String read() { return "Читаю роман «" + title + "»"; }
    @Override public int getPages() { return pages; }

    @Override
    public boolean lend() {
        if (!available) return false;
        available = false;
        return true;
    }

    @Override
    public boolean returnBook() {
        if (available) return false;
        available = true;
        return true;
    }

    @Override public boolean isAvailable() { return available; }
}
```

## 5. Перегрузка и переопределение

```java
public class Computer {
    public String run() { return "Компьютер работает"; }
    public String run(String program) { return "Запускает " + program; }
    public String run(int processes) { return "Запускает " + processes + " процессов"; }

    public String getPerformance() { return "Средняя"; }
}
```

```java
public class GamingPC extends Computer {
    @Override
    public String getPerformance() { return "Высокая"; }

    // собственная перегрузка
    public String run(String game, int fps) {
        return "Игра " + game + ", " + fps + " FPS";
    }
}
```

```java
Computer c = new Computer();
System.out.println(c.run());
System.out.println(c.run("Word"));
System.out.println(c.run(12));

Computer g = new GamingPC();
System.out.println(g.getPerformance());   // "Высокая" — runtime

if (g instanceof GamingPC) {
    GamingPC pc = (GamingPC) g;
    System.out.println(pc.run("Cyberpunk", 120));
}
```

Перегрузка — **разные параметры**. Переопределение — **та же сигнатура** в наследнике.

```java
public class Hotel {
    private final int id;
    private final String name;
    private int stars;
    private final List<Integer> guestRatings;

    public Hotel(int id, String name, int stars, List<Integer> ratings) {
        this.id = id;
        this.name = name;
        this.stars = stars;
        this.guestRatings = new ArrayList<>(ratings);
    }

    public double getAverageRating() {
        if (guestRatings.isEmpty()) return 0.0;
        double sum = 0;
        for (int r : guestRatings) sum += r;
        return sum / guestRatings.size();
    }

    public int getId() { return id; }
    public String getName() { return name; }
    public int getStars() { return stars; }
    public void setStars(int stars) {
        if (stars < 1 || stars > 5) throw new IllegalArgumentException("1..5");
        this.stars = stars;
    }
}
```

## 8. Своё исключение и обработка

```java
public class InvalidUserDataException extends Exception {
    private final String field;

    public InvalidUserDataException(String field, String message) {
        super(message);
        this.field = field;
    }
    public String getField() { return field; }
}
```

```java
public class User {
    private final String username;
    private String email;
    private final String password;

    public User(String username, String email, String password)
            throws InvalidUserDataException {
        if (username == null || username.isBlank()) {
            throw new InvalidUserDataException("username", "Пустое имя");
        }
        if (email == null || !email.contains("@")) {
            throw new InvalidUserDataException("email", "Плохой email");
        }
        if (password == null || password.length() < 6) {
            throw new InvalidUserDataException("password", "Пароль < 6");
        }
        this.username = username;
        this.email = email;
        this.password = password;
    }

    public void updateEmail(String newEmail) throws InvalidUserDataException {
        if (newEmail == null || !newEmail.contains("@")) {
            throw new InvalidUserDataException("email", "Плохой email");
        }
        this.email = newEmail;
    }

    public String getUsername() { return username; }
    public String getEmail() { return email; }
}
```

```java
try {
    User user = new User("alex", "alex@mail.ru", "secret1");
    user.updateEmail("bad");
} catch (InvalidUserDataException e) {
    System.out.println("Ошибка в поле " + e.getField() + ": " + e.getMessage());
} finally {
    System.out.println("Всегда");
}
```

## 10. Меню и Maven

```java
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        boolean running = true;

        while (running) {
            System.out.println("1. Задание");
            System.out.println("0. Выход");
            System.out.print("Выберите действие: ");

            String input = sc.next();
            int choice;
            try {
                choice = Integer.parseInt(input);
            } catch (NumberFormatException e) {
                choice = -1;
            }

            switch (choice) {
                case 1 -> task();
                case 0 -> { running = false; }
                default -> System.out.println("Неверный выбор");
            }
        }
        sc.close();
    }

    static void task() {
        System.out.println("--- Задание ---");
    }
}
```

## Чек-лист «код компилируется»

- [ ] Имя файла = имя `public` класса.
- [ ] `package by.epam.learn;` первой строкой.
- [ ] Поля `private`, доступ через методы.
- [ ] В конструкторе наследника `super(...)` — первая строка.
- [ ] Над переопределёнными методами `@Override`.
- [ ] Для `List`/`Map` указаны generic-типы.
- [ ] `IOException`/своё checked-исключение обработано или объявлено в `throws`.
- [ ] Нет `new` для абстрактного класса/интерфейса.
- [ ] В `switch` есть `default` или `->` (Java 14+).
- [ ] После `Scanner` не забыт `close()` (в учебном коде допустимо).
