# Исключения (ЛР13)

> [!abstract] Одной фразой
> Исключение — объект, описывающий ошибку во время выполнения. Его можно
> перехватить (`catch`), пробросить (`throws`) или создать своё.

## Иерархия

```text
Throwable
├── Error                 — системные ошибки, обычно не обрабатываем
│   ├── OutOfMemoryError
│   └── StackOverflowError
└── Exception
    ├── RuntimeException  — unchecked (не проверяются компилятором)
    │   ├── NullPointerException
    │   ├── ArithmeticException
    │   ├── ArrayIndexOutOfBoundsException
    │   └── NumberFormatException
    └── checked           — проверяются компилятором
        ├── IOException
        ├── FileNotFoundException
        └── SQLException
```

| Вид | Наследник | Компилятор требует обработку | Примеры |
|-----|-----------|------------------------------|---------|
| checked | `Exception` (кроме `RuntimeException`) | да | `IOException`, `SQLException` |
| unchecked | `RuntimeException` | нет | `NPE`, `ArithmeticException` |
| error | `Error` | нет (и не нужно) | `OutOfMemoryError` |

> [!important] Формулировка
> Checked-исключение — это «предусмотренная проблема» (файл не найден,
> сеть недоступна). Unchecked — «ошибка программиста» (деление на ноль,
> выход за границу массива, `null`).

## Ключевые слова

```java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Ошибка: " + e.getMessage());
} finally {
    System.out.println("Выполнится всегда");
}
```

```java
public void read(String path) throws IOException {
    Files.readAllLines(Path.of(path));
}
```

```java
if (amount < 0) {
    throw new IllegalArgumentException("Сумма не может быть отрицательной");
}
```

| Слово | Смысл |
|-------|-------|
| `try` | опасный код |
| `catch` | обработка конкретного типа |
| `finally` | выполняется всегда |
| `throw` | создать и бросить исключение |
| `throws` | объявить в сигнатуре метода |

- `throw` — внутри метода, один объект.
- `throws` — в заголовке метода, список типов.

## `finally`

Выполняется всегда, даже если был `return` или исключение.

```java
try {
    return 1;
} finally {
    System.out.println("finally");
}
```

Не выполнится только при `System.exit(0)` (и при падении JVM).

> [!warning] Ловушка
> `return` внутри `finally` перекрывает предыдущий `return` и может «съесть»
> исключение. Так писать нельзя.

## Несколько `catch`

Порядок — от конкретного к общему:

```java
try {
    // ...
} catch (ArithmeticException e) {
    // конкретно
} catch (RuntimeException e) {
    // шире
} catch (Exception e) {
    // совсем общий
}
```

Если общий `catch` поставить первым — ошибка компиляции: до специфичного
код никогда не дойдёт.

## Multi-catch (Java 7+)

```java
try {
    int x = Integer.parseInt(text);
    int y = 10 / x;
} catch (NumberFormatException | ArithmeticException e) {
    System.out.println("Ошибка: " + e.getMessage());
}
```

- типы в `|` не должны быть наследниками друг друга;
- переменная `e` неявно `final`;
- обработка одинаковая для всех перечисленных типов.

## `try-with-resources` (Java 7+)

```java
try (BufferedReader reader = Files.newBufferedReader(Path.of("data.txt"), StandardCharsets.UTF_8)) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
} catch (IOException e) {
    System.out.println("Ошибка чтения: " + e.getMessage());
}
```

- ресурс должен реализовывать `AutoCloseable`;
- `close()` вызывается автоматически;
- несколько ресурсов закрываются в обратном порядке;
- исключение при закрытии добавляется как suppressed.

```java
try (var in = Files.newInputStream(src);
     var out = Files.newOutputStream(dst)) {
    in.transferTo(out);
}
```

## Свои исключения

### Checked

```java
public class InsufficientFundsException extends Exception {
    private final double requested;
    private final double balance;

    public InsufficientFundsException(String message, double requested, double balance) {
        super(message);
        this.requested = requested;
        this.balance = balance;
    }
    public double getRequested() { return requested; }
    public double getBalance() { return balance; }
}
```

### Unchecked

```java
public class InvalidAgeException extends RuntimeException {
    private final int age;
    public InvalidAgeException(String message, int age) {
        super(message);
        this.age = age;
    }
    public int getAge() { return age; }
}
```

Правило: хочешь заставить обработать — наследуй от `Exception`; хочешь
сигнализировать об ошибке программиста — от `RuntimeException`.

## Код варианта 9 (ЛР13)

```java
public class InvalidUserDataException extends Exception {
    private final String field;

    public InvalidUserDataException(String field, String message) {
        super(message);
        this.field = field;
    }
    public String getField() { return field; }
}
```

```java
public class UserNotFoundException extends Exception {
    private final String username;

    public UserNotFoundException(String username) {
        super("Пользователь " + username + " не найден");
        this.username = username;
    }
    public String getUsername() { return username; }
}
```

```java
public class AuthenticationException extends Exception {
    private final String username;
    private final int attempts;

    public AuthenticationException(String username, int attempts) {
        super("Пользователь " + username + ": неверный пароль (попытка " + attempts + ")");
        this.username = username;
        this.attempts = attempts;
    }
    public String getUsername() { return username; }
    public int getAttempts() { return attempts; }
}
```

```java
public class User {
    private static final Pattern EMAIL =
        Pattern.compile("^[\\w.%+-]+@[\\w.-]+\\.[A-Za-z]{2,}$");

    private final String username;
    private String email;
    private final String password;
    private final int age;
    private int failedAttempts;

    public User(String username, String email, String password, int age)
            throws InvalidUserDataException {
        if (username == null || username.isBlank()) {
            throw new InvalidUserDataException("username", "Имя не может быть пустым");
        }
        if (email == null || !EMAIL.matcher(email).matches()) {
            throw new InvalidUserDataException("email", "Некорректный email: " + email);
        }
        if (password == null || password.length() < 6) {
            throw new InvalidUserDataException("password", "Пароль минимум 6 символов");
        }
        if (age < 0 || age > 150) {
            throw new InvalidUserDataException("age", "Возраст 0..150");
        }
        this.username = username;
        this.email = email;
        this.password = password;
        this.age = age;
    }

    public void authenticate(String password) throws AuthenticationException {
        if (!this.password.equals(password)) {
            failedAttempts++;
            throw new AuthenticationException(username, failedAttempts);
        }
        failedAttempts = 0;
    }

    public void updateEmail(String newEmail) throws InvalidUserDataException {
        if (newEmail == null || !EMAIL.matcher(newEmail).matches()) {
            throw new InvalidUserDataException("email", "Некорректный email: " + newEmail);
        }
        this.email = newEmail;
    }

    public String getUsername() { return username; }
    public String getEmail() { return email; }
    public int getAge() { return age; }
}
```

```java
public class UserService {
    private final Map<String, User> users = new LinkedHashMap<>();

    public void register(User user) throws InvalidUserDataException {
        if (users.containsKey(user.getUsername())) {
            throw new InvalidUserDataException("username", "Пользователь уже существует");
        }
        users.put(user.getUsername(), user);
    }

    public User find(String username) throws UserNotFoundException {
        User user = users.get(username);
        if (user == null) throw new UserNotFoundException(username);
        return user;
    }

    public void login(String username, String password)
            throws UserNotFoundException, AuthenticationException {
        find(username).authenticate(password);
    }

    public void updateEmail(String username, String email)
            throws UserNotFoundException, InvalidUserDataException {
        find(username).updateEmail(email);
    }
}
```

### Демонстрация

```java
UserService service = new UserService();

try {
    service.register(new User("alex", "alex@mail.ru", "secret1", 20));
    service.register(new User("bad", "bad@mail", "123", 20));
} catch (InvalidUserDataException e) {
    System.out.println("Ошибка в поле " + e.getField() + ": " + e.getMessage());
} finally {
    System.out.println("Операция регистрации завершена");
}

try {
    service.login("alex", "wrong");
} catch (AuthenticationException e) {
    System.out.println(e.getMessage());
}

try {
    service.login("ghost", "secret1");
} catch (UserNotFoundException e) {
    System.out.println(e.getMessage());
}
```

## Что спросят на защите

1. **Что такое исключение?** Объект с информацией об ошибке времени выполнения.
2. **Иерархия?** `Throwable` → `Error` / `Exception` → `RuntimeException`.
3. **Checked vs unchecked?** Первые проверяет компилятор, вторые — нет.
4. **Ключевые слова?** `try`, `catch`, `finally`, `throw`, `throws`.
5. **`try-catch-finally`?** Попытка, обработка, гарантированный блок.
6. **`throw` vs `throws`?** Бросить объект vs объявить в сигнатуре.
7. **Когда `finally`?** Всегда, кроме `System.exit`.
8. **Как создать своё?** Наследовать `Exception`/`RuntimeException`, вызвать `super(message)`.
9. **`try-with-resources`?** Автозакрытие `AutoCloseable`-ресурсов.
10. **Несколько типов?** Несколько `catch` или multi-catch через `|`.
11. **Multi-catch?** `catch (A | B e)`, типы не связаны наследованием.
12. **Деление на ноль?** `ArithmeticException`.
13. **Не обработали?** Исключение идёт вверх, при отсутствии обработчика программа падает.
14. **Сообщение?** `e.getMessage()`, полный стек — `e.printStackTrace()`.
15. **Stack trace?** Список вызовов от места ошибки до `main`.
16. **Несколько ресурсов?** Перечислить через `;`, закроются в обратном порядке.

> [!tip] Фраза для ответа
> «Я разделяю ошибки на предусмотренные и программные. Для первых делаю
> checked-исключения и заставляю вызывающий код их обработать, для вторых —
> unchecked. Ресурсы закрываю через try-with-resources, чтобы не терять
> исключения при закрытии».
