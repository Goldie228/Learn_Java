# Конспект: Лабораторная работа №11

**Тема:** Разработка, отладка и испытание программ с использованием полиморфизма.

---

## 1. Полиморфизм
**Полиморфизм** — способность одного имени или ссылки работать с объектами
разных типов. В Java два основных вида:
- **статический** (времени компиляции) — перегрузка методов;
- **динамический** (времени выполнения) — переопределение методов.
## 2. Перегрузка (overloading)
Несколько методов с одним именем, но разными списками параметров. Компилятор
выбирает версию по количеству и типам аргументов.
```java
public class Computer {
    public String run() { return "Компьютер работает"; }
    public String run(String program) { return "Запускает " + program; }
    public String run(int processes) { return "Запускает " + processes + " процессов"; }
}
```

Версии должны отличаться параметрами; возвращаемого типа недостаточно.
Наследник получает перегрузки базового класса и может добавить свои,
например `run(String game, int fps)`.
## 3. Переопределение (overriding)
Наследник объявляет метод с **тем же именем, параметрами и возвращаемым типом**.
Аннотация `@Override` проверяет корректность; доступ нельзя сужать.
```java
class Computer  { public String getPerformance() { return "Средняя"; } }
class GamingPC extends Computer {
    @Override public String getPerformance() { return "Высокая"; }
}
```

## 4. Динамическое связывание
Если переменная базового типа ссылается на объект наследника, вызывается
переопределённый метод наследника:
```java
Computer pc = new GamingPC("Aurora X", 32, 2000, "NVIDIA RTX 4080");
System.out.println(pc.getPerformance());   // Высокая
```

Компилятор видит методы базового класса, а JVM выбирает реализацию по
фактическому типу. Поэтому полиморфный список работает единообразно:
```java
List<Computer> computers = List.of(
        new GamingPC("Aurora X", 32, 2000, "NVIDIA RTX 4080"),
        new OfficePC("Office Line", 8, 256, 23.8));
for (Computer computer : computers) {
    System.out.println(computer.displayInfo());
}
```

## 5. Перегрузка и переопределение
Перегрузка меняет параметры и выбирается компилятором, переопределение
сохраняет сигнатуру и выбирается JVM по фактическому типу объекта.
## 6. instanceof и нисходящее приведение
`instanceof` проверяет фактический тип перед приведением. В Java 21
pattern-форма сразу создаёт переменную нужного типа:
```java
for (Computer computer : computers) {
    if (computer instanceof GamingPC gaming) {
        System.out.println(gaming.run("Cyberpunk 2077", 120));
    } else if (computer instanceof OfficePC office) {
        System.out.println(office.run("Excel", true));
    }
}
```

Приведение **вверх** (`GamingPC → Computer`) безопасно всегда; приведение
**вниз** (`Computer → GamingPC`) требует `instanceof`, иначе возможен
`ClassCastException`.

## 7. Контрольные вопросы кратко
1. Полиморфизм — единый интерфейс для разных реализаций.
2. Перегрузка меняет параметры; переопределение сохраняет сигнатуру.
3. Перегруженная версия определяется статическими типами аргументов.
4. Динамическое связывание выбирает метод по фактическому типу объекта.
5. `instanceof` нужен для безопасного нисходящего приведения.
