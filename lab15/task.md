# Лабораторная работа №15

**Тема:** Разработка, отладка и испытание программ с использованием системы
управления версиями Git. Работа с GitHub.

**Вариант:** 9

## Задание

Последовательно перенести все лабораторные работы в единый Git-репозиторий,
используя обычное слияние веток с созданием merge-коммита.

Порядок выполнения:

1. Для каждой лабораторной работы создать отдельную ветку `lr1`, `lr2`, …, `lrN`
   (или `lab1`, `lab2`, …, `labN`).
2. По завершении работы создать Pull Request и слить его в основную ветку
   обычным merge — так, чтобы создавался отдельный коммит слияния
   (merge-коммит).
3. Перед началом следующей работы создавать новую ветку от актуального
   состояния основной ветки, при необходимости делать rebase (или merge)
   относительно `master`, после чего снова сливать через Pull Request.

## Что требуется показать

- локальный репозиторий с основной веткой `main`;
- 15 веток `lr1`…`lr15` и 15 merge-коммитов;
- настроенный `.gitignore`;
- демонстрацию разрешения конфликта слияния;
- описание работы с удалённым репозиторием GitHub и Pull Request;
- итоговый граф истории `git log --graph --oneline --decorate`.
