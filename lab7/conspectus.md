## 1. Статические поля

Кроме обычных полей и методов, класс может иметь **статические** (от англ.
*static* — «статичный, неизменный») поля, методы, константы и инициализаторы.

Обычные (нестатические) поля хранят **состояние объекта** — у каждого объекта
своя копия. Статические поля хранят **состояние всего класса** — они общие для
всех объектов и создаются в единственном экземпляре. Память для них
выделяется **даже до создания первого объекта**.

```java
class Person {
    int age;                  // обычное поле (копия на каждый объект)
    static int retirementAge = 65;  // статическое поле (одно на весь класс)
}
```

Обращение к статическому полю — **через имя класса**:

```java
System.out.println(Person.retirementAge);  // 65
Person.retirementAge = 67;                 // изменение
```

Внутри самого класса к статическому полю можно обращаться и без имени класса
(см. `checkAge()` ниже) — и метод класса видит обновлённое значение.

## 2. Статические методы

Статический метод относится к классу, а не к объекту; вызывается через имя
класса, объект для этого создавать не нужно:

```java
static double getAverageCourse() {
    return (double) totalCourses / totalStudents;
}
...
double avg = Student.getAverageCourse();
```

Правило: **статический метод не может обращаться к нестатическим полям и
вызывать нестатические методы напрямую** (у него нет `this`, т. к. объекта
может не быть). Обратное можно: обычный метод свободно использует статические
поля.

Понадобиться статическое поле в нестатическом методе:

```java
void checkAge() {
    if (age >= retirementAge)   // age — обычное, retirementAge — статическое
        System.out.println("Уже на пенсии");
}
```

## 3. Пример из теории: класс Person

```java
class Person {
    int age;                    // обычное поле
    static int retirementAge;   // статическое поле

    static {                    // статический инициализатор
        retirementAge = 65;
        System.out.println("Static initializer");
    }

    Person(int age) {
        this.age = age;
        System.out.println("Constructor");
    }

    void checkAge() {
        if (age >= retirementAge)
            System.out.println("Уже на пенсии");
        else
            System.out.printf("Сколько лет осталось до пенсии: %d%n",
                    retirementAge - age);
    }
}
```

```java
public static void main(String[] args) {
    Person tom = new Person(41);
    tom.checkAge();          // Сколько лет осталось до пенсии: 24
    Person bob = new Person(68);
    bob.checkAge();          // Уже на пенсии

    System.out.println(Person.retirementAge);  // 65
    Person.retirementAge = 67;                 // изменение
    System.out.println(Person.retirementAge);  // 67
}
```

Порядок выполнения: при **первом** обращении к классу выполняется статический
инициализатор (`Static initializer` выводится один раз), затем при каждом
`new` — конструктор (`Constructor`).

## 4. Общая статистика на счётчиках (для ИДЗ)

Шаблон всех заданий ИДЗ (в том числе **задание 3 — «Студенты»**):

```java
public class Student {
    private String name; private int course; private String group;

    private static int totalStudents;   // счётчик объектов
    private static int totalCourses;    // сумма курсов

    public Student(String name, int course, String group) {
        ...
        totalStudents++;
        totalCourses += course;
    }

    public static double getAverageCourse() {
        if (totalStudents == 0) return 0.0;
        return (double) totalCourses / totalStudents;
    }
}
```

Конструктор увеличивает оба счётчика; `getAverageCourse()` — статический метод
статистики. Вызов: `Student.getAverageCourse()`.

## 5. Статический метод main

Точка входа программы — статический метод, потому что вызывается системой
**без создания объекта главного класса**:

```java
public static void main(String[] args) { }
```

## Контрольные вопросы

1. **Как создается и вызывается статическое поле.** Создаётся объявлением
   с ключевым словом `static` (`static int x = 5;`), память выделяется при
   загрузке класса. Вызывается через имя класса: `ClassName.x` (внутри класса
   — просто по имени).
2. **Как создается и вызывается статический метод.** Объявление `static`
   перед типом возвращаемого значения; вызов через имя класса
   `ClassName.method()` без объекта.
3. **Отличие от нестатических.** Статические — принадлежат классу, в одном
   экземпляре, общие для всех объектов, доступны без объекта, выделяются до
   создания объектов, не видят `this` и не могут напрямую обращаться к
   обычным полям/методам. Нестатические — копия на каждый объект, живут пока
   жив объект, доступны только через объект.

## Шпаргалка: static vs не- static

| Признак | обычное поле/метод | `static` поле/метод |
|---|---|---|
| Владелец | объект | класс |
| Экземпляров | по одному на объект | один на весь класс |
| Вызов | `obj.f()` | `Class.f()` |
| `this` | есть | нет |
| Живёт | пока существует объект | всё время работы класса |
