## Задание

**Задание 3, вариант 3.** Класс «Студенты» (`Student`):

- нестатические поля: `name`, `course`, `group`;
- статические поля: `totalStudents` (счётчик), `totalCourses` (сумма курсов);
- статический метод `getAverageCourse()`;
- в `main` создать 6 студентов и вывести средний курс.

Конструктор увеличивает оба статических счётчика. Также откомпилирован
пример из теории — класс `Person` со статическим полем `retirementAge` и
статическим инициализатором (пункт меню 2).

## Теория для защиты

### Контрольные вопросы (из задания)

1. **Как создаётся и вызывается статическое поле.**
   Создаётся объявлением с `static` (`static int retirementAge = 65;`).
   Память выделяется при загрузке класса — ещё до создания объектов.
   Вызывается через имя класса: `Person.retirementAge`; внутри своего класса —
   просто по имени поля.

2. **Как создаётся и вызывается статический метод.**
   Объявление `static` перед типом возвращаемого значения. Вызывается через
   имя класса без объекта: `Student.getAverageCourse()`.

3. **Отличие статических полей и методов от нестатических.**
   Статические принадлежат **классу**, существуют в одном экземпляре, общие
   для всех объектов, доступны без объекта, выделяются в памяти до создания
   объектов, не имеют `this` и не могут напрямую обращаться к обычным полям и
   методам. Нестатические (обычные) принадлежат **объекту** — у каждого
   объекта своя копия поля, доступны только через объект и живут, пока жив
   объект.

### Что рассказать о своей работе

1. `Student`: обычные поля `name`/`course`/`group` + статические
   `totalStudents`/`totalCourses` — наглядная разница «состояние объекта» и
   «состояние класса».
2. Конструктор увеличивает оба счётчика — статистика накапливается сама.
3. `getAverageCourse()` — статический метод: вызывается как
   `Student.getAverageCourse()`, объект не нужен; защищён от деления на ноль.
4. `resetStatistics()` — тоже статический (обнуление для повторных запусков).
5. Пример `Person`: статическое поле `retirementAge`, статический
   инициализатор выводится **один раз** при первом обращении к классу —
   продемонстрировать на экране.
6. Показать тесты (`mvn test`) и вывод пунктов меню 1–2.
