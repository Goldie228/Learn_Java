## Задание

**Задание 9, вариант 9.** Пять пунктов по файловому вводу/выводу:

1. Создать файл с информацией о своём университете. Вывести данные об этом
   файле. Вывести информацию из файла.
2. Ввести с клавиатуры в файл `f` 10 целых чисел. Вывести их на экран и найти
   разность максимального и минимального.
3. Создать текстовый файл `f` со случайными целыми числами. Записать в файл
   `g` все числа, кратные 7, а в файл `h` — все остальные.
4. Ввести с клавиатуры в файл 15 вещественных значений силы тока. Считать
   данные и вывести среднюю силу тока.
5. Создать текстовый файл `f` с 10 целыми числами. Вывести количество чисел,
   не равных нулю.

## Реализация

Вся файловая логика вынесена в класс `FileTaskService` и покрыта тестами.
Для каждого пункта используется свой подкаталог, чтобы файлы не
перезаписывали друг друга:

| Пункт | Каталог | Файлы |
|---|---|---|
| 1 | `data/task1` | `university.txt` |
| 2 | `data/task2` | `f.txt` |
| 3 | `data/task3` | `f.txt`, `g.txt`, `h.txt` |
| 4 | `data/task4` | `f.txt` |
| 5 | `data/task5` | `f.txt` |

### Методы `FileTaskService`

| Метод | Назначение |
|---|---|
| `createUniversityFile(Path dir)` | создаёт `university.txt` со сведениями об учебном заведении |
| `printFileInfo(Path path)` | выводит имя, размер, дату модификации, родительский и абсолютный путь, права, тип |
| `writeInts` / `readInts` | запись и чтение целых чисел по одному в строке |
| `differenceMaxMin(List<Integer>)` | разность max и min; для пустого списка — `IllegalArgumentException` |
| `writeDoubles` / `readDoubles` | запись и чтение вещественных чисел |
| `average(List<Double>)` | среднее значение; для пустого списка — `0.0` |
| `createRandomIntFile(file, count, min, max)` | файл из случайных чисел через `Random` |
| `splitMultiples(source, multiples, rest, divisor)` | разбиение чисел на кратные делителю и остальные |
| `countNonZero(List<Integer>)` | количество чисел, не равных нулю |
| `printContent(Path file)` | построчный вывод содержимого файла |

Все операции используют `java.nio.file.Files`, кодировку `StandardCharsets.UTF_8`,
`Files.createDirectories` для родительских каталогов и try-with-resources для
потоков. При вводе с клавиатуры число проверяется: при ошибке запрос
повторяется без падения программы.

## Теория для защиты

### Контрольные вопросы

1. **Поток (stream)** — абстракция последовательного ввода/вывода; скрывает
   источник данных (файл, консоль, сеть) за единым интерфейсом.
2. **Базовые классы:** байтовые — `InputStream`/`OutputStream`, символьные —
   `Reader`/`Writer`.
3. **`InputStream`:** `read()`, `read(byte[])`, `available()`, `skip()`,
   `close()`.
4. **`OutputStream`:** `write(int)`, `write(byte[])`, `flush()`, `close()`.
5. **`File`** описывает путь и свойства файла или каталога, позволяет узнать
   размер, права, список содержимого каталога.
6. **`FileInputStream`/`FileOutputStream`** работают с байтами и не
   предназначены для текста в Unicode.
7. **Буферизованные потоки** накапливают данные в памяти и уменьшают число
   обращений к диску.
8. **`Path`/`Files`** дают удобный API, явную кодировку, безопасную работу
   с каталогами и атомарные операции.
9. **Классов много**, потому что поток собирается из слоёв: источник →
   буфер → преобразование (байты/символы) → форматирование.
10. **`IOException` — checked**, его нужно обработать или объявить в
    `throws`; try-with-resources автоматически закрывает ресурсы даже при
    исключении. Несколько ресурсов перечисляются в `try (...)` через `;`.

### Что рассказать о своей работе

1. `FileTaskService` — вся логика отделена от меню, поэтому тестируется без
   консоли.
2. Для каждого пункта свой каталог `data/taskN`, файлы не конфликтуют.
3. Везде используется `StandardCharsets.UTF_8` и try-with-resources;
   `Files.createDirectories` создаёт родительские каталоги.
4. Пункт 1: `Files.size`, `Files.getLastModifiedTime`, `Files.isRegularFile`
   и другие характеристики выводятся в читаемом виде.
5. Пункт 2: `differenceMaxMin` отдельно обрабатывает пустой список
   (`IllegalArgumentException`).
6. Пункт 3: кратность проверяется через `value % divisor == 0`, поэтому
   `0` и отрицательные числа попадают в файл `g`; нулевой делитель
   запрещён.
7. Пункт 4: среднее считается как сумма / количество, для пустого списка
   возвращается `0.0`.
8. Пункт 5: `countNonZero` пропускает нули и считает остальные значения.
9. `mvn test` — 14 тестов, включая отрицательные сценарии и проверку UTF-8.
