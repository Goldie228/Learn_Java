Тема: Разработка, отладка и испытание программ с использованием
файлового ввода и вывода.

Цель: Научить читать и записывать данные в файлы с использованием
потоков ввода-вывода Java, корректно обрабатывать ошибки и освобождать
ресурсы.

Время выполнения: 4 часа

ПОРЯДОК ВЫПОЛНЕНИЯ РАБОТЫ

1. Изучить теоретические сведения;
2. Ответить на контрольные вопросы;
3. Откомпилировать примеры программ из раздела «Теоретические сведения»;
4. Выполнить ИДЗ.

КОНТРОЛЬНЫЕ ВОПРОСЫ

1. Что такое поток (stream) в Java и какую задачу решает эта абстракция?
2. Какие два базовых абстрактных класса являются прародителями всех
   байтовых потоков, и какие – всех символьных?
3. Перечислите основные методы класса InputStream и опишите их назначение.
4. Перечислите основные методы класса OutputStream и опишите их назначение.
5. Для чего предназначен класс File и какие задачи он позволяет решать?
6. Чем отличаются классы FileInputStream и FileOutputStream и какие у них
   есть ограничения?
7. Для чего предназначены буферизованные потоки
   (BufferedInputStream/BufferedOutputStream)?
8. Какие преимущества даёт использование классов Path и Files из пакета
   java.nio.file по сравнению с классом File?
9. Почему в стандартной библиотеке Java такое большое количество классов
   для ввода/вывода?
10. Почему обработка исключений try-catch при работе с потоками является
    обязательной. Как использовать try-with-resources с несколькими
    ресурсами?

ЗАДАНИЕ 9 (ВАРИАНТ 9)

1. Создать файл с информацией о своём университете. Вывести данные
   об этом файле. Вывести информацию из файла.
2. Ввести с клавиатуры в файл «f» 10 целых чисел. Вывести их на экран
   и найти разность максимального и минимального.
3. Создать текстовый файл «f» со случайными целыми числами. Записать
   в файл «g» все числа, кратные 7, а в файл «h» – все остальные.
4. Ввести с клавиатуры в файл 15 вещественных значений силы тока.
   Считать данные и вывести среднюю силу тока.
5. Создать текстовый файл «f» с 10 целыми числами. Вывести количество
   чисел, не равных нулю.
