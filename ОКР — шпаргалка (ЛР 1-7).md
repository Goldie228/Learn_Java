# ЛР 1. Алгоритмические конструкции

## Базовые типы данных

Java — статически типизированный язык, размер типов **не зависит от платформы**.

| Тип | Бит | По умолчанию | Диапазон / описание |
|-----|:---:|:---:|---------------------|
| `boolean` | 8 | `false` | `true` / `false` |
| `byte` | 8 | `0` | −128 … 127 |
| `char` | 16 | `'\u0000'` | символ Unicode (0 … 65535) |
| `short` | 16 | `0` | −32 768 … 32 767 |
| `int` | 32 | `0` | −2³¹ … 2³¹−1 (~2 млрд) |
| `long` | 64 | `0L` | −2⁶³ … 2⁶³−1 |
| `float` | 32 | `0.0f` | 7 значащих цифр |
| `double` | 64 | `0.0d` | 15 значащих цифр |

Базовые типы всегда инициализируются значением по умолчанию; ссылочные — `null`.

## Операторы

- **Арифметические:** `+ - * / %`. Целочисленное деление отбрасывает дробь: `7 / 2 == 3`.
- **Сравнения:** `== != > < >= <=`. Для объектов `==` сравнивает **ссылки**, содержимое — только `equals()`.
- **Логические:** `&&` (И), `||` (ИЛИ), `!` (НЕ). Работает short-circuit: второй операнд не вычисляется, если результат уже ясен.
- **Присваивание** — операция, возвращает значение: `a = b = 1;`
- **Инкремент/декремент:**

| Форма | Результат |
|-------|-----------|
| `y++` | возвращает **старое** значение, потом +1 |
| `++y` | сначала +1, возвращает **новое** значение |
| `y--`, `--y` | то же для −1 |

## Литералы

| Тип | Пример | Формат |
|-----|--------|--------|
| Целые | `42`, `100L` | суффикс `l`/`L` — long |
| Вещественные | `3.14`, `2.5f`, `2.5D` | `f`/`F` — float, иначе double |
| Логические | `true`, `false` | |
| Символьные | `'A'`, `'ж'` | апострофы, 1 символ |
| Строковые | `"Hello"` | двойные кавычки |

## Управляющие конструкции

```java
if (условие) { ... } else { ... }

while (условие) { ... }          // цикл с предусловием
do { ... } while (условие);      // с постусловием: тело минимум 1 раз

for (инициализация; условие; инкремент) { ... }

switch (выражение) {
    case значение1: ...; break;
    default: ...;
}
```

- **`switch`:** без `break` выполнение «проваливается» в следующий `case`.
- **`break`** — выход из цикла/switch; **`continue`** — переход к следующей итерации.
- `for` — когда число итераций известно; `while` — когда нет.

## Структура программы и ввод/вывод

```java
import java.util.Scanner;

public class Program {                       // имя файла = имя класса
    public static void main(String[] args) { // точка входа
        // public — доступен всем; static — без объекта; void — ничего не возвращает
        System.out.println("Текст");         // с переводом строки
        System.out.print("Текст");           // без перевода
        System.out.printf("%.2f%n", x);      // форматированный

        Scanner sc = new Scanner(System.in);
        int a = sc.nextInt();
        double b = sc.nextDouble();
        String s = sc.nextLine();            // строка с пробелами
    }
}
```

## Приведение типов

- **Widening (неявное):** `byte → short → int → long → float → double`.
- **Narrowing (явное):** `int y = (int) x;` — дробная часть отбрасывается: `(int) 3.99 == 3`.

## Комментарии и Javadoc

| Вид | Синтаксис |
|-----|-----------|
| Однострочный | `// текст` |
| Многострочный | `/* ... */` |
| Javadoc | `/** ... */` — генерация HTML: `javadoc File.java` |

Дескрипторы: `@author`, `@param`, `@return`, `@throws`, `@exception`.

# ЛР 2. Массивы

Массив — **объект** фиксированной длины: поле `length` + элементы с индексами `0 … length-1`.

## Создание

```java
int[] nums;                                // объявление ссылки (Java-стиль, предпочтительно)
nums = new int[5];                         // создание: 5 нулей
int[] arr = new int[5];
int[] arr = {1, 2, 3, 4, 5};              // список: размер НЕ указывается
int[] arr = new int[]{10, 20, 30};        // то же самое
```

Значения по умолчанию: `0`, `0L`, `0.0f`, `0.0`, `false`, `'\u0000'`, ссылки — `null`.

## Работа с элементами

```java
int[] nums = {10, 20, 30};
nums[0];                            // 10 — индексация с нуля
nums[nums.length - 1];              // последний элемент
nums.length                         // поле (НЕ метод!)
```

## Перебор

```java
for (int i = 0; i < nums.length; i++) { ... }   // по индексам
for (int n : nums) { ... }                      // for-each
```

## Заполнение

```java
nums[i] = sc.nextInt();          // с клавиатуры в цикле
nums[i] = rand.nextInt(100);     // случайные 0..99 (java.util.Random)
Arrays.fill(nums, 42);           // всё одним значением
```

## Копирование

```java
// 1) цикл: dst[i] = src[i];
// 2) Arrays.copyOf(src, src.length);
System.arraycopy(src, 0, dst, 0, src.length);   // 3) системное
```

⚠️ `arr2 = arr1` копирует **ссылку**, а не данные — обе переменные укажут на один массив.

## Двумерные массивы (матрицы)

Двумерный массив — **массив массивов**.

```java
int[][] m = new int[3][4];                        // 3 строки × 4 столбца
int[][] m = {{1,2,3},{4,5,6},{7,8,9}};            // инициализация списком
int[][] jagged = new int[3][];                    // строки разной длины
jagged[0] = new int[]{1, 2};
jagged[1] = new int[]{3, 4, 5};

m.length            // число строк
m[i].length         // число столбцов в строке i
m[1][2]             // 2-я строка, 3-й столбец

for (int i = 0; i < m.length; i++)
    for (int j = 0; j < m[i].length; j++) { ... }
```

## Диагонали квадратной матрицы N×N

```java
matrix[i][i]           // главная диагональ: [0][0], [1][1], [2][2]
matrix[i][n - 1 - i]   // побочная:        [0][2], [1][1], [2][0]
```

## Методы `java.util.Arrays`

```java
Arrays.sort(nums);                // сортировка
Arrays.toString(nums);            // строковое представление
Arrays.copyOf(src, len);          // копирование
Arrays.fill(nums, value);         // заполнение
Arrays.equals(a, b);              // сравнение содержимого
Arrays.binarySearch(nums, key);   // поиск (массив должен быть отсортирован!)
```

## Исключения массивов

| Ошибка | Причина |
|--------|---------|
| `ArrayIndexOutOfBoundsException` | выход за границы |
| `NullPointerException` | массив не создан |
| `NegativeArraySizeException` | `new int[-5]` |

# ЛР 3. Строки

## Классы

| Класс | Изменяемость | Применение |
|-------|--------------|------------|
| `String` | immutable (неизменяемая) | обычные строки |
| `StringBuilder` | mutable, **не** потокобезопасный | много конкатенаций в цикле (быстрее) |
| `StringBuffer` | mutable, синхронизированный | многопоточность |

⚠️ `String` неизменяем: любой «изменяющий» метод создаёт **новый** объект. Литералы хранятся в String Pool и переиспользуются.

## Создание

```java
String s1 = "Привет";                 // литерал → пул строк
String s2 = new String("Привет");     // отдельный объект
String s3 = new String(charArray);    // из char[]
String empty = "";                    // пустая строка
```

## Основные методы `String`

```java
s.length()                     // длина
s.charAt(0)                    // символ по индексу
s.toUpperCase() / toLowerCase()
s.trim()                       // убрать пробелы по краям
s.contains("World")            // поиск подстроки → boolean
s.startsWith("He") / s.endsWith("lo")
s.indexOf('o') / s.lastIndexOf('o')   // -1, если не найдено
s.indexOf("World")
s.replace('o','0') / s.replace("World","Java") / s.replaceAll("[aeiou]","*")
s.substring(6)                 // с индекса 6 до конца
s.substring(0, 5)              // [0; 5) — 5 не включается
s.split(",")                   // → String[]
s.toCharArray()                // → char[]
```

## Сравнение и конкатенация

```java
a.equals(b)              // содержимое, с учётом регистра
a.equalsIgnoreCase(c)    // без учёта регистра
a.compareTo(b)           // 0 — равны, <0 / >0 — порядок

"Мама " + "мыла " + "раму"        // оператор + (единственный перегруженный)
a.concat(b).concat(c)             // метод concat()
```

## Число ↔ строка

```java
String.valueOf(42);  Integer.toString(42);    // число → строка
Integer.parseInt("42");  Double.parseDouble("3.14");   // строка → число
```

## `StringBuilder`

```java
StringBuilder sb = new StringBuilder("Hello");
sb.append(" World");       // добавить в конец
sb.insert(5, ",");         // вставить
sb.delete(5, 6);           // удалить
sb.replace(6, 11, "Java"); // заменить
sb.reverse();              // развернуть
String result = sb.toString();
```

`StringBuffer` — тот же интерфейс, методы синхронизированы (для многопоточности).

## Форматирование `printf`

| Формат | Значение |
|--------|----------|
| `%s` | строка |
| `%d` | целое |
| `%f` | вещественное |
| `%n` | перевод строки |
| `%.2f` | 2 знака после запятой |
| `%5d` / `%-15s` | выравнивание вправо / влево |

```java
System.out.printf("Имя: %s, Возраст: %d, Зарплата: %.2f%n", name, age, salary);
```

## Регулярные выражения

```java
import java.util.regex.*;

Pattern p = Pattern.compile("\\d+");
Matcher m = p.matcher("abc123def456");
while (m.find()) {
    m.group();   // "123", затем "456"
}
```

- `Matcher`: `find()` — следующее совпадение, `matches()` — вся строка, `group()` — найденное, `start()`/`end()` — индексы.
- `Pattern`: `compile(regex)`, `matches(regex, input)`, `split(input)`.

### Классы символов

| Символ | Значение | Эквивалент |
|--------|----------|------------|
| `.` | любой символ | — |
| `\d` / `\D` | цифра / не цифра | `[0-9]` / `[^0-9]` |
| `\s` / `\S` | пробел / не пробел | |
| `\w` / `\W` | буква, цифра, `_` / нет | `[0-9_A-Za-z]` |

### Квантификаторы и группировка

| Запись | Значение |
|--------|----------|
| `X*` | 0 или более |
| `X+` | 1 или более |
| `X?` | 0 или 1 |
| `X{n}` / `X{n,}` / `X{n,m}` | ровно n / от n / от n до m |
| `(X)` | группа |
| `[abc]`, `[^abc]`, `[a-z]` | один из / кроме / диапазон |
| `X|Y` | X или Y |

Примеры: `\d+` — числа; `[\w.]+@[\w.]+` — email; `\s+` — пробелы; слово из 'a' и букв/цифр: `\ba[a-z0-9]+a\b`.

# ЛР 4. Maven

## Зачем системы сборки

Автоматизируют: компиляцию, тесты, упаковку (`jar`/`war`), управление зависимостями, публикацию.

## Maven vs Gradle

| Критерий | Maven | Gradle |
|----------|-------|--------|
| Конфигурация | XML (`pom.xml`) | Groovy/Kotlin DSL |
| Модель | линейные фазы | граф задач (DAG) |
| Инкрементность | ограниченная | полная |
| Гибкость | ниже | выше |
| Плагины | больше | растёт |
| Порог входа | ниже | выше |

**Gradle** (2007) — открытая система сборки, DSL на Groovy/Kotlin, штатная для Android (2013).

## Жизненный цикл (команды)

Фазы выполняются по порядку; вызов фазы выполняет все предыдущие.

| Команда | Действие |
|---------|----------|
| `mvn clean` | удалить `target` |
| `mvn validate` | проверить доступность информации |
| `mvn compile` | компиляция |
| `mvn test` | тесты |
| `mvn package` | упаковка в jar/war |
| `mvn verify` | проверки пакета |
| `mvn install` | в локальный репозиторий `~/.m2` |
| `mvn site` | документация |
| `mvn deploy` | в удалённый репозиторий |

Комбинируют: `mvn clean package`, `mvn clean install`.

## Структура проекта и pom.xml

```
lab4/
├── pom.xml
├── src/main/java/by/epam/learn/App.java      — код
├── src/test/java/by/epam/learn/AppTest.java  — тесты
└── target/                                    — результат сборки
```

```xml
<project>
    <modelVersion>4.0.0</modelVersion>
    <groupId>by.epam.learn</groupId>     <!-- организация -->
    <artifactId>lab4</artifactId>        <!-- имя проекта -->
    <version>1.0-SNAPSHOT</version>      <!-- версия -->
    <packaging>jar</packaging>
    <dependencies>
        <dependency>
            <groupId>junit</groupId>
            <artifactId>junit</artifactId>
            <version>4.11</version>
            <scope>test</scope>
        </dependency>
    </dependencies>
</project>
```

- **GAV** (groupId : artifactId : version) — уникальные координаты артефакта.
- **Scope:** `compile` (по умолчанию), `test` (только тесты), `provided` (даёт среда), `runtime` (только при запуске).

## Генерация и запуск

```bash
mvn archetype:generate \
    -DgroupId=by.epam.learn -DartifactId=lab4 \
    -DarchetypeArtifactId=maven-archetype-quickstart \
    -DarchetypeVersion=1.4 -DinteractiveMode=false

mvn clean package
java -cp target/classes by.epam.learn.App
mvn dependency:tree          # дерево зависимостей
```

# ЛР 5. Классы и объекты

## Структура класса

```java
public class Cat {
    private int weight;          // атрибут (поле) — состояние объекта
    private String name;

    public void eat() { ... }    // метод — поведение

    public String speak(String words) {
        return words + "...mauu...";
    }
}
```

Сигнатура `public String speak(String words)`: `public` — доступ; `String` — тип возврата (`void` — ничего); `speak` — имя (с маленькой буквы); `(String words)` — параметры; `return` — возврат значения.

## Создание объекта

```java
Cat ourcat = new Cat();      // new — создаёт объект, ourcat — ссылка на него
ourcat.eat();
String say = ourcat.speak("Play with me");
```

## Конструкторы

Имя совпадает с именем класса, **нет типа возврата**, вызывается при `new`.

```java
public Rectangle(double width, double height) {
    this.width = width;      // this — ссылка на текущий объект,
    this.height = height;    // снимает конфликт имён поля и параметра
}
```

Если конструктор не объявлен — компилятор создаёт **конструктор по умолчанию** без параметров.

## Массив объектов

Массив хранит **ссылки** на объекты.

```java
Book[] books = { new Book("Война и мир", "Л. Н. Толстой", 1869),
                 new Book("Евгений Онегин", "А. С. Пушкин", 1833) };

for (Book b : books) System.out.println(b);   // работает, если есть toString()

// поиск min/max обычным перебором по полю:
Book oldest = books[0];
for (Book b : books) if (b.getYear() < oldest.getYear()) oldest = b;
```

## Перечисления (enum)

До Java 5 наборы констант делали через `static final int` — небезопасно и нечитаемо; теперь `enum`:

```java
public enum Gender {
    MALE("мужской"), FEMALE("женский");   // экземпляры создаются БЕЗ new

    private final String ru;
    Gender(String ru) { this.ru = ru; }    // конструктор не public/protected

    @Override public String toString() { return ru; }
}
```

| Метод | Описание |
|-------|----------|
| `values()` | массив всех элементов (в порядке объявления) |
| `valueOf(String)` | элемент по имени |
| `ordinal()` | позиция (с нуля) |
| `name()` | имя элемента |
| `compareTo(T)` | сравнение |

Конструктор вызывается автоматически для каждого элемента. Запрещено: быть суперклассом/подклассом, абстрактным, параметризованным, создавать через `new`.

# ЛР 6. Инкапсуляция

**Инкапсуляция** — принцип ООП: данные и методы их обработки объединены в классе, доступ к внутреннему состоянию ограничен. Зачем: спрятать реализацию, защитить данные, дать контролируемый доступ, избежать ошибок.

Средства: **модификаторы доступа** + **геттеры/сеттеры**.

## Модификаторы доступа

| Модификатор | Класс | Пакет | Наследники | Весь мир |
|-------------|:-----:|:-----:|:----------:|:--------:|
| `public` | + | + | + | + |
| `protected` | + | + | + | – |
| `default` (без слова) | + | + | – | – |
| `private` | + | – | – | – |

## Геттеры и сеттеры

```java
class MyClass {
    private String s = "Hello World!";   // скрытое поле: obj.s — ошибка компиляции

    public String getS() { return s; }              // геттер — чтение
    public void setS(String newValue) { s = newValue; }  // сеттер — запись
}
```

Смысл: поле скрыто, а в сеттер можно добавить **проверку**:

```java
public void Set(int v) {
    if (v >= 1 && v <= 7) value = v;   // Set(100) проигнорируется — защита состояния
}
```

## Иерархия классов и наследование

- **Иерархия** — классы, связанные «родитель — потомок»; корень — `Object`.
- Наследование (`extends`): `public`/`protected` наследуются и доступны; `private` — наследуются, но доступны только через методы родителя; `default` — только в своём пакете.
- **Конструкторы не наследуются** — вызываются через `super(...)`.

# ЛР 7. Статические поля и методы

## static-поле

Обычное поле — состояние **объекта** (копия у каждого). Статическое — состояние **класса** (одна копия на всех), память выделяется при загрузке класса, **до** создания объектов.

```java
class Person {
    int age;                             // копия на каждый объект
    static int retirementAge = 65;       // одно на весь класс
}

Person.retirementAge;        // вызов через имя класса
Person.retirementAge = 67;   // изменение
```

## static-метод

```java
static double getAverageCourse() { return (double) totalCourses / totalStudents; }

Student.getAverageCourse();  // через имя класса, объект не нужен
```

⚠️ **Правило:** статический метод **не может** напрямую обращаться к нестатическим полям/методам (нет `this` — объекта может не быть). Обратное можно: обычный метод свободно использует статические поля.

## Статический инициализатор и порядок выполнения

```java
static { retirementAge = 65; }   // выполняется ОДИН раз при первом обращении к классу
```

Порядок: при первом обращении к классу → статический инициализатор → затем при каждом `new` → конструктор.

## Шаблон счётчиков (для заданий)

```java
private static int totalStudents;   // счётчик объектов
private static int totalCourses;    // сумма

public Student(...) { ...; totalStudents++; totalCourses += course; }

public static double getAverageCourse() {
    if (totalStudents == 0) return 0.0;      // защита от деления на ноль
    return (double) totalCourses / totalStudents;
}
```

## static vs не-static

| Признак | обычное | `static` |
|---------|---------|----------|
| Владелец | объект | класс |
| Экземпляров | по одному на объект | один на класс |
| Вызов | `obj.f()` | `Class.f()` |
| `this` | есть | нет |
| Живёт | пока жив объект | всё время работы класса |

**Почему `main` — static:** система вызывает его без создания объекта главного класса.

# Вопросы ОКР с краткими ответами

### ЛР 1
1. **Базовые типы Java?** — 8 типов (см. таблицу); размеры фиксированы, не зависят от платформы, значения по умолчанию есть у всех.
2. **Инкремент/декремент?** — `++y` возвращает новое значение, `y++` — старое; обе увеличивают на 1.
3. **Типы литералов?** — целые (`42`, `100L`), вещественные (`3.14`, `2.5f`), логические, символьные (`'A'`), строковые (`"Hello"`).
4. **Дескрипторы Javadoc?** — `@author`, `@param`, `@return`, `@throws`, `@exception`.
5. **`==` vs `equals()`?** — для объектов `==` сравнивает ссылки, `equals()` — содержимое.
6. **`while` vs `do-while`?** — `do-while` выполняет тело минимум 1 раз.
7. **Зачем `break` в switch?** — иначе «провал» в следующий case.

### ЛР 2
1. **Способы создания массивов?** — `new int[5]`; список `{1,2,3}`; `new int[]{...}`; 2D: `new int[3][4]` или списком.
2. **Способы заполнения?** — вручную, цикл + Scanner, `Random`, `Arrays.fill`.
3. **Индексация?** — с 0. `length` — **поле**, не метод.
4. **`arr[10]` при длине 5?** — `ArrayIndexOutOfBoundsException`.
5. **`arr2 = arr1`?** — копируется ссылка, не данные; для данных — цикл / `Arrays.copyOf` / `System.arraycopy`.
6. **Jagged array?** — массив строк разной длины; `matrix[i].length` — столбцы строки i.
7. **Диагонали?** — главная `[i][i]`, побочная `[i][n-1-i]`.

### ЛР 3
1. **Что такое строка?** — объект класса `String`, упорядоченная последовательность символов, неизменяемая.
2. **Способы создания?** — литерал, `new String(...)`, из `char[]`.
3. **Конкатенация?** — `+` (единственный перегруженный оператор) или `concat()`.
4. **Классы regex?** — `Pattern` (компиляция) и `Matcher` (поиск). `Pattern.compile()` → `m.find()` → `m.group()`.
5. **StringBuilder vs StringBuffer?** — одинаковый интерфейс; Builder быстрее (не синхронизирован), Buffer потокобезопасен.

### ЛР 4
1. **Gradle?** — открытая система сборки на Groovy/Kotlin DSL, граф задач, инкрементная, штатная для Android.
2. **Maven?** — сборка Java-проектов, конфигурация `pom.xml`, линейные фазы, репозитории и кэш `~/.m2`.
3. **Отличия?** — Maven: XML, фиксированные фазы, стандарты, много плагинов; Gradle: DSL, DAG, гибче и быстрее, сложнее.
4. **Команды фаз?** — `clean → validate → compile → test → package → verify → install → site → deploy`.
5. **GAV?** — groupId : artifactId : version — координаты артефакта.

### ЛР 5
1. **Структура класса?** — `[модификатор] class Имя { поля; конструкторы; методы; }`.
2. **Как создаётся объект?** — оператором `new`: `Cat ourcat = new Cat();`.
3. **Конструктор?** — метод с именем класса без возвращаемого типа; если не объявлен — конструктор по умолчанию без параметров.
4. **Что такое enum и как записывается?** — типобезопасный набор констант: `enum Gender { MALE, FEMALE }`; класс-наследник `java.lang.Enum`, экземпляры без `new`.
5. **Зачем `this`?** — ссылка на текущий объект, различает поля и параметры с одинаковыми именами.

### ЛР 6
1. **Что такое инкапсуляция?** — объединение данных и методов в классе + ограничение доступа (private + get/set).
2. **Что такое иерархия классов?** — классы, связанные наследованием; корень `Object`.
3. **Как наследуются поля/методы?** — public/protected доступны, private только через методы родителя, default — в пакете; конструкторы не наследуются.
4. **Модификаторы доступа?** — `public` (всем), `default` (пакет), `protected` (пакет + наследники), `private` (только класс).
5. **Геттеры/сеттеры?** — чтение/запись скрытого поля; дают контроль (проверки в сеттере).

### ЛР 7
1. **Как создаётся/вызывается static-поле?** — объявление со `static`, память при загрузке класса; вызов `ClassName.x` (внутри класса — по имени).
2. **Как создаётся/вызывается static-метод?** — `static` перед типом возврата; вызов `ClassName.method()` без объекта.
3. **Отличие от нестатических?** — статические принадлежат классу (один экземпляр, без `this`, не видят обычные поля); нестатические — объекту (копия каждому, живут с объектом).

```java
// Типы: boolean(8) byte(8) char(16) short(16) int(32) long(64) float(32) double(64)
// int: -2^31..2^31-1; индексация массивов/строк — с 0

// Массив
int[] a = {1,2,3}; a.length; for (int x : a) {}
int[][] m = new int[3][4]; m.length; m[i].length;
главная: m[i][i];  побочная: m[i][n-1-i];

// Строки
s.length() charAt() substring(a,b) indexOf() replace() split() trim()
s.equals() equalsIgnoreCase() compareTo()
StringBuilder: append insert delete replace reverse toString()
printf: %s %d %f %.2f %5d %-15s %n
regex: \d \w \s  * + ? {n,m}  Pattern.compile → matcher.find → group

// ООП
new Class();  this.x = x;   // конструктор без типа возврата
private поля + public get/set  = инкапсуляция
public > protected > default > private
static: Class.field / Class.method(); нет this; НЕ видит нестатические члены

// Maven
pom.xml, GAV, scope: compile/test/provided/runtime
mvn clean package | mvn test | mvn install;  target/, ~/.m2
```
