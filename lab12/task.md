ЗАДАНИЕ 1 (ВАРИАНТ 9). ИНСТРУМЕНТЫ

Базовый класс «Tool»:
- поля: «name», «id», «weight»;
- конструктор, геттеры, метод «displayInfo()».

Наследники:
1. «Hammer» — поле «handleLength»;
2. «Screwdriver» — поле «tipType»;
3. «Wrench» — поле «size».

Создайте «Map<String, Tool>» с названием как ключом, добавьте 3 Hammer,
3 Screwdriver, 2 Wrench, выведите все ключи и значения и размер Map.
Продемонстрируйте перезапись значения при повторной вставке ключа.

ЗАДАНИЕ 2 (ВАРИАНТ 9). ОТЕЛИ

Класс «Hotel»:
- поля: «id», «name», «city», «stars», «guestRatings» (List<Integer>);
- методы: «getAverageRating()», «getStars()», «setStars()», «addRating()».

Операции:
1. Вывести отели со средним рейтингом < 3.
2. Повысить звёздность отелей со средним рейтингом >= 4 (не выше 5).
3. «printHotels(List<Hotel> hotels, int stars)» — печать отелей с заданным
   количеством звёзд.
4. Упорядочить все отели по убыванию среднего рейтинга. При совпадении —
   в алфавитном порядке по названию. Вывести ID, название и средний рейтинг.
