## 1. Инкапсуляция

**Инкапсуляция** (от англ. encapsulation — «обернуть в капсулу») — принцип ООП,
при котором данные и методы их обработки объединяются в классе, а доступ к
внутреннему состоянию объекта ограничивается.

Зачем нужна инкапсуляция:

- спрятать детали реализации класса;
- защитить данные от случайного/неправомерного изменения;
- дать удобный контролируемый доступ через специальные методы;
- предотвратить трудноуловимые ошибки из-за некорректного состояния.

Средства инкапсуляции в Java:

- **модификаторы доступа** (`public`, `default`, `protected`, `private`);
- **геттеры и сеттеры** — методы чтения и записи полей.

---

## 2. Модификаторы доступа

| Модификатор | Класс | Пакет | Наследники | Весь мир |
|-------------|:-----:|:-----:|:----------:|:--------:|
| `public`    | +     | +     | +          | +        |
| `protected` | +     | +     | +          | –        |
| `default`   | +     | +     | –          | –        |
| `private`   | +     | –     | –          | –        |

- `public` — «публичный», доступен всем.
- `default` — модификатор по умолчанию (не пишется явно); виден только в
  пределах своего пакета.
- `protected` — как `default`, но доступен ещё и классам-наследникам
  (в том числе из других пакетов).
- `private` — «частный», виден только самому классу.

Модификаторы пишутся перед объявлением переменных, методов и классов.

### Пример: защита поля

```java
class MyClass {
    public String s = "Hello World!";   // доступно снаружи: obj.s
}

class MyClass {
    private String s = "Hello World!";  // obj.s → ошибка компиляции
}
```

## 3. Геттеры и сеттеры

- **Геттер** (от get — «получать») — метод, возвращающий значение поля.
- **Сеттер** (от set — «устанавливать») — метод, задающий значение поля.

```java
class MyClass {
    private String s = "Hello World!";

    public String getS() {          // геттер
        return s;
    }

    public void setS(String newValue) {  // сеттер
        s = newValue;
    }
}
```

```java
MyClass obj = new MyClass();
System.out.println(obj.getS());   // Hello World!
obj.setS("It's modified!");
System.out.println(obj.getS());   // It's modified!
```

Зачем, если результат тот же? Геттер и сеттер дают **контроль**: в сеттер можно
добавить проверку (например, не задавать значение меньше определённой длины),
а поле при этом остаётся скрытым.

## 4. Пример: класс DayWeek

Класс хранит день недели в скрытом поле `value`; доступ — только через методы,
причём `Set` проверяет корректность значения (1..7):

```java
class DayWeek {
    private int value;              // скрытая переменная

    DayWeek() {                     // конструктор без модификатора (package-private)
        value = 1;                  // по умолчанию "Monday"
    }

    public int Get() {              // чтение
        return value;
    }

    public void Set(int v) {        // запись с проверкой
        if ((v >= 1) && (v <= 7)) {
            value = v;
        }
    }

    public String GetName() {       // производный метод
        String day = "Monday";
        switch (value) {
            case 2: day = "Tuesday"; break;
            case 3: day = "Wednesday"; break;
            case 4: day = "Thursday"; break;
            case 5: day = "Friday"; break;
            case 6: day = "Saturday"; break;
            case 7: day = "Sunday"; break;
        }
        return day;
    }
}
```

Если задать `Set(100)`, значение не изменится — защита состояния работает.

## 5. Иерархия классов и наследование (для контрольных вопросов)

- **Иерархия классов** — структура, в которой классы связаны отношением
  «родитель — потомок»; корень — `Object`.
- Наследование (`extends`): потомок получает поля и методы родителя.
  - `public` и `protected` члены наследуются и доступны;
  - `private` члены наследуются, но напрямую недоступны — только через
    унаследованные `public`/`protected` методы;
  - `default` члены доступны наследнику только в том же пакете.
- Конструкторы **не наследуются**; вызываются через `super(...)`.

## 6. Краткая шпаргалка

```java
public class Account {
    private double balance;          // скрытое поле

    public Account(double balance) {
        setBalance(balance);         // проверка в конструкторе
    }

    public double getBalance() {     // геттер
        return balance;
    }

    public void setBalance(double balance) {   // сеттер с проверкой
        if (balance >= 0) {
            this.balance = balance;
        }
    }
}
```
