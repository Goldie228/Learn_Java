## Лабораторная работа №4 — Maven

### Задание

Сгенерировать проект с помощью Maven, заменить фразу `"Hello, world"` на
`"Hello, ИМЯ"`, скомпилировать и запустить.

### Реализация

Стандартный Maven-проект:

```
lab4/
├── pom.xml
└── src
    ├── main/java/by/epam/learn/App.java
    └── test/java/by/epam/learn/AppTest.java
```

Проект сгенерирован архетипом `maven-archetype-quickstart`:

```bash
mvn archetype:generate \
    -DgroupId=by.epam.learn \
    -DartifactId=lab4 \
    -Dversion=1.0-SNAPSHOT \
    -DarchetypeGroupId=org.apache.maven.archetypes \
    -DarchetypeArtifactId=maven-archetype-quickstart \
    -DarchetypeVersion=1.4 \
    -DinteractiveMode=false
```

Структура:

```
lab4/
├── pom.xml
└── src
    ├── main/java/by/epam/learn/App.java
    └── test/java/by/epam/learn/AppTest.java
```

`App.java` (строка `"Hello World!"` заменена на `"Hello, ИМЯ!"`):

```java
package by.epam.learn;

public class App {
    public static void main(String[] args) {
        String name = (args.length > 0) ? args[0] : "Глеб";
        System.out.println("Hello, " + name + "!");
    }
}
```

`pom.xml` (ключевое): координаты GAV, `maven.compiler.release=21`,
тестовая зависимость JUnit 4.11.

### Сборка и запуск

```bash
cd lab4
mvn clean package
java -cp target/classes by.epam.learn.App "Глеб"
```

Результат:

```
Hello, Глеб!
```

Тесты: `Tests run: 1, Failures: 0, Errors: 0, Skipped: 0` — `BUILD SUCCESS`.

## Контрольные вопросы

### Работа №4

1. **Gradle** — система автоматизации сборки с открытым исходным кодом, DSL
   на Groovy/Kotlin, граф задач (DAG), инкрементная сборка; штатная для Android.
2. **Maven** — система сборки Java-проектов с XML-конфигурацией `pom.xml`,
   линейной моделью фаз жизненного цикла и управлением зависимостями.
3. **Отличия** — Maven: XML + фиксированные фазы, стандартная структура, много
   плагинов. Gradle: код + граф задач, гибче и быстрее, но сложнее.
4. **Команды** — `clean`, `validate`, `compile`, `test`, `package`, `verify`,
   `install`, `site`, `deploy`.

### Работа №5

1. **Структура класса** — `[модификатор] class Имя { поля; конструкторы; методы; }`.
2. **Методы** — `[модификатор] ТипВозврата имя(параметры) { ... return ...; }`.
3. **Экземпляр** — `new`: `Cat ourcat = new Cat();`.
4. **Синтаксис** — `public class Cat { private int weight; public void eat() {...} }`.
5. **Перечисление** — `enum Gender { MALE, FEMALE }`; это класс-наследник
   `java.lang.Enum`, объекты создаются без `new`.
