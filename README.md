## Сборка и запуск

Для работ №4–№14 используется Maven (JDK 21+):

```bash
cd lab8
mvn clean package
java -cp target/classes by.epam.learn.Main
```

Модульные тесты:

```bash
mvn test
```

Работы №1–№3 собираются напрямую компилятором:

```bash
cd lab1
javac Main.java
java Main
```
