## Предварительная настройка (Fedora 43)

### 1. Установка JDK

```bash
sudo dnf install java-21-openjdk-devel
```

### 2. Проверка установки

```bash
java -version
javac -version
```

### 3. Настройка JAVA_HOME (опционально)

```bash
# Узнать путь к JDK
dirname $(dirname $(readlink -f $(which java)))

# Добавить в ~/.bashrc
echo 'export JAVA_HOME=/usr/lib/jvm/java-21-openjdk' >> ~/.bashrc
source ~/.bashrc
```

## Теория для защиты

### Контрольные вопросы (из задания)

1. **Базовые типы данных Java** — 8 типов: `boolean`, `byte`, `char`, `short`, `int`, `long`, `float`, `double`. Размеры фиксированы и не зависят от платформы. Все базовые типы инициализируются значениями по умолчанию.

2. **Операции инкремента и декремента** — `++y` (префикс) возвращает **новое** значение, `y++` (постфикс) — **старое**. Обе формы увеличивают переменную на 1. Аналогично для `--`.

3. **Типы литералов Java** — целые (`42`, `100L`), вещественные (`3.14`, `2.5f`), логические (`true`/`false`), символические (`'A'`), строковые (`"Hello"`).

4. **Дескрипторы комментариев Java** — `@author`, `@param`, `@return`, `@throws`, `@exception`. Используются в блочных комментариях `/** */` для генерации документации (javadoc).

### Дополнительные вопросы, которые могут спросить

**Типы данных и переменные:**
- В чём разница между `==` и `equals()` для объектов? (`==` сравнивает ссылки, `equals()` — содержимое)
- Что такое widening и narrowing conversion? (неявное расширение vs явное сужение типов)
- Почему `char` в Java занимает 16 бит? (символы Unicode)

**Операторы:**
- В чём разница между `/` для целых и вещественных чисел? (целочисленное отбрасывает дробную часть)
- Как работает оператор `%` с отрицательными числами? (знак результата совпадает с делимым)
- Что такое short-circuit evaluation у `&&` и `||`? (второй операнд не вычисляется, если результат уже определён)

**Управляющие конструкции:**
- Чем `while` отличается от `do-while`? (`do-while` выполняет тело минимум 1 раз)
- Когда использовать `for`, а когда `while`? (`for` — когда известно число итераций, `while` — когда условие неизвестно заранее)
- Зачем нужен `break` в `switch`? (без него выполнение проваливается в следующий case)

**Ввод/вывод:**
- Чем `println` отличается от `print`? (`println` добавляет перевод строки)
- Как читать строку с пробелами? (`nextLine()` вместо `next()`)
