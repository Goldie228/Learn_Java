## 1. Базовые типы данных

Java — статически типизированный язык. Размер типов **не зависит от платформы**.

| Тип     | Размер (бит) | Значение по умолчанию | Диапазон / Описание                        |
|---------|:------------:|:---------------------:|--------------------------------------------|
| `boolean` | 8            | `false`               | `true` или `false`                         |
| `byte`    | 8            | `0`                   | -128 … 127                                 |
| `char`    | 16           | `'\u0000'`            | Символ Unicode (0 … 65535)                 |
| `short`   | 16           | `0`                   | -32 768 … 32 767                           |
| `int`     | 32           | `0`                   | -2^31 … 2^31-1 (~2 млрд)                  |
| `long`    | 64           | `0L`                  | -2^63 … 2^63-1                             |
| `float`   | 32           | `0.0f`                | 7 значащих цифр                            |
| `double`  | 64           | `0.0d`                | 15 значащих цифр                           |

**Ключевое:** все базовые типы инициализируются значениями по умолчанию. Ссылочные типы (массивы, объекты) — `null`.

## 2. Операторы

### 2.1. Присваивание `=`
В Java присваивание — это **операция** (не оператор). Она возвращает присвоенное значение:
```java
a = b = 1;   // сначала b=1, потом a=1
```

### 2.2. Арифметические
`+`, `-`, `*`, `/`, `%` (остаток от деления)

Особенность целочисленного деления: `7 / 2 = 3` (дробная часть отбрасывается).

### 2.3. Сравнения
| Оператор | Значение                |
|----------|-------------------------|
| `==`     | Равно                   |
| `!=`     | Не равно                |
| `>`      | Больше                  |
| `<`      | Меньше                  |
| `>=`     | Больше или равно        |
| `<=`     | Меньше или равно        |

**Важно:** `==` для объектов сравнивает **ссылки**, а не содержимое. Для сравнения содержимого — метод `equals()`.

### 2.4. Логические
`&&` (И), `||` (ИЛИ), `!` (НЕ)

### 2.5. Инкремент / Декремент
| Форма     | Действие               | Результат               |
|-----------|------------------------|-------------------------|
| `y++`     | `y = y + 1`            | Старое значение `y`     |
| `++y`     | `y = y + 1`            | Новое значение `y`     |
| `y--`     | `y = y - 1`            | Старое значение `y`     |
| `--y`     | `y = y - 1`            | Новое значение `y`     |

## 4. Управляющие конструкции

### 4.1. Условный оператор `if`
```java
if (условие) {
    // если true
} else {
    // если false
}
```

### 4.2. Цикл `while` (по предусловию)
```java
while (условие) {
    // тело цикла
}
```

### 4.3. Цикл `do-while` (по постусловию)
```java
do {
    // тело цикла
} while (условие);   // тело выполняется минимум 1 раз
```

### 4.4. Цикл `for`
```java
for (инициализация; условие; инкремент) {
    // тело цикла
}
```

### 4.5. Оператор `switch`
```java
switch (выражение) {
    case значение1:
        // операторы
        break;
    case значение2:
        // операторы
        break;
    default:
        // операторы
}
```
**Важно:** без `break` выполнение «проваливается» в следующий `case`.

### 4.6. `break` и `continue`
- `break` — немедленный выход из цикла или `switch`
- `continue` — переход к следующей итерации цикла (пропуск остатка тела)

|---------|-----------------|-----------------------------------|
| Однострочный | `// текст` | Комментарий до конца строки        |

## 6. Структура Java-программы

```java
import java.util.Scanner;   // подключение пакета

public class Program {      // имя файла = имя класса
    public static void main(String[] args) {
        // входная точка программы
    }
}
```

- `public` — доступен отовсюду
- `static` — не требует создания экземпляра класса
- `void` — не возвращает значение
- `String[] args` — аргументы командной строки

## 7. Ввод/вывод

### Вывод:
```java
System.out.println("Текст");   // с переводом строки
System.out.print("Текст");     // без перевода строки
System.out.printf("%.2f", x);  // форматированный вывод
```

### Ввод (Scanner):
```java
import java.util.Scanner;

Scanner sc = new Scanner(System.in);
int a = sc.nextInt();       // чтение int
double b = sc.nextDouble(); // чтение double
String s = sc.nextLine();   // чтение строки
```

## 8. Типы данных при присваивании

```java
int a = 10;          // целое
double b = 3.14;     // вещественное
char c = 'A';        // символ
String s = "Hello";  // строка (объект)
boolean f = true;    // логическое
```

**Неявное присваивание (widening):** `byte -> short -> int -> long -> float -> double`

**Явное приведение (narrowing):** `double -> int` — теряется дробная часть:
```java
double x = 3.99;
int y = (int) x;   // y = 3
```
