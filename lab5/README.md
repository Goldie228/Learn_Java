## Теория для защиты

### Контрольные вопросы (из задания)

1. **Структура класса в Java.**
   `[модификатор] class Имя { поля; конструкторы; методы; }`. Поля хранят
   состояние, методы — поведение, конструкторы создают объекты.

2. **Как создаются методы класса?**
   `[модификатор] ТипВозврата имя(параметры) { тело; return ...; }`.
   Если метод ничего не возвращает — тип `void`.

3. **Каким образом создается экземпляр класса?**
   Оператором `new`: `Cat ourcat = new Cat();` — создаётся объект в памяти,
   переменная-ссылка указывает на него.

4. **Синтаксис класса.**
   `public class Cat { private int weight; public void eat() { ... } }`.

5. **Что такое перечисление и как записывается?**
   Типобезопасный набор именованных констант: `enum Gender { MALE, FEMALE }`.
   Перечисление — это класс (наследник `java.lang.Enum`), может иметь поля,
   конструкторы и методы; экземпляры создаются без `new`.

### Дополнительные вопросы

- **Инкапсуляция:** поля `private`, доступ через `get`/`set`; защищает
  состояние объекта от некорректного изменения извне.
- **`this`:** ссылка на текущий объект, снимает конфликт имён полей и параметров.
- **Конструктор по умолчанию:** создаётся компилятором, если не объявлен ни один
  конструктор.
- **`toString()`:** переопределяется для удобного вывода объекта.
- **`enum` vs `static final int`:** `enum` типобезопасен, читаем, поддерживает
  методы и поля.
- **`values()` / `ordinal()` / `valueOf()`:** получить все элементы, позицию
  элемента, элемент по имени.
