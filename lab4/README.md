## Задание

По порядку выполнения работы:

1. Сгенерировать проект с помощью Maven.
2. Заменить фразу `"Hello, world"` на `"Hello, ИМЯ"`.
3. Скомпилировать и запустить.

Проект сгенерирован архетипом `maven-archetype-quickstart`:

```bash
mvn archetype:generate \
    -DgroupId=by.epam.learn \
    -DartifactId=lab4 \
    -Dversion=1.0-SNAPSHOT \
    -DarchetypeGroupId=org.apache.maven.archetypes \
    -DarchetypeArtifactId=maven-archetype-quickstart \
    -DarchetypeVersion=1.4 \
    -DinteractiveMode=false
```

В сгенерированном `App.java` строка `"Hello World!"` заменена на
`"Hello, ИМЯ!"`; имя можно передать аргументом командной строки, иначе
используется имя по умолчанию.

## Предварительная настройка (Fedora 43)

### 1. Установка JDK и Maven

```bash
sudo dnf install java-21-openjdk-devel maven
```

### 2. Проверка установки

```bash
java -version
mvn -version
```

> В Fedora 43 файл `/etc/java/maven.conf` может быть «битой» символической
> ссылкой на `/usr/share/jpbinding/maven.conf`. Если `mvn -version` выдаёт
> ошибку про `maven.conf`, можно указать JDK явно:
>
> ```bash
> JAVA_HOME=/usr/lib/jvm/java-21-openjdk mvn -version
> ```

## Сборка и запуск

Перейти в каталог проекта:

```bash
cd ~/Progs/Learn_Java/lab4
```

### Компиляция и упаковка

```bash
mvn clean package
```

Команда компилирует исходники, прогоняет тесты и собирает
`target/lab4-1.0-SNAPSHOT.jar`.

### Запуск

```bash
java -cp target/classes by.epam.learn.App "Глеб"
```

Результат:

```
Hello, Глеб!
```

Если запустить без аргумента — используется имя по умолчанию:

```
$ java -cp target/classes by.epam.learn.App
Hello, Глеб!
```

## Теория для защиты

### Контрольные вопросы (из задания)

1. **Что такое Gradle?**
   Система автоматизации сборки с открытым исходным кодом, использующая DSL
   на Groovy/Kotlin и направленный ациклический граф задач. Поддерживает
   инкрементную сборку, штатная система сборки Android.

2. **Что такое Maven?**
   Инструмент автоматизации сборки Java-проектов, конфигурация которого
   описывается XML-файлом `pom.xml`. Работает по линейной модели фаз
   жизненного цикла, управляет зависимостями через репозитории и локальный кэш.

3. **В чём их отличие?**
   Maven — XML и фиксированные фазы, стандартная структура, много плагинов.
   Gradle — код на Groovy/Kotlin и граф задач, гибче и быстрее за счёт
   инкрементности, но сложнее для новичка.

4. **Команды для работы:**
   `clean`, `validate`, `compile`, `test`, `package`, `verify`, `install`,
   `site`, `deploy`.

### Что рассказать о своей работе

1. Проект создан по стандартной структуре Maven (`src/main/java`, `src/test/java`).
2. В `pom.xml` заданы координаты GAV, версия Java (`maven.compiler.release=21`)
   и тестовая зависимость JUnit 4.
3. Фраза `"Hello, world"` заменена на приветствие с именем в методе `App.main()`.
4. Сборка выполняется командой `mvn clean package`, запуск — `java -cp target/classes`.
5. Тесты (`AppTest`) прогоняются командой `mvn test`.
6. Продемонстрировать сборку, запуск и результат тестов.
